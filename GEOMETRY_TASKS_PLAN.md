## Зачем

Раздел «Геометрия → Задачи» неудобен: работа собирается тремя разными кнопками
(«Рабочий лист», «Просмотр», «Листы A5») с разным смыслом, найденная поиском
задача открывается печатной ячейкой A5 с редактором макета, а вместо работ
учителя заводят темы («Экзамен 7 кл», «ВПР», «Каникулярное ДЗ»).

Цель — устроить раздел **так же понятно, как классический контур** (банк →
карточка задачи → сборка → работа → печать/журнал), но **своими сущностями**,
с геометрическим оттенком: крупный чертёж, фасеты, стереоредактор, генератор
сечений.

## Решения пользователя (01.10.2026)

- **Раздел остаётся отдельным.** `geometry_tasks` в `tasks` НЕ переносим и с
  обычными задачами не приравниваем. Мост «В задачи» / «В геометрию» остаётся
  как есть (копирование).
- **В работах нужны варианты.**
- **Фасеты общие:** свои задачи размечаются теми же фасетами, что и банк МЦНМО
  (`geometry_tags`: объект / метод / факт).
- **Ссылка ученику — позже** (не в первых этапах).
- **Генератор сечений — делаем.**

## Целевое устройство

Меню «Геометрия»: **Банк задач** · **Работы** · **Генератор сечений** ·
Планиметрия · Стереометрия · Темы и фасеты.

### 1. Единый банк

- Один экран вместо двух режимов. **Область** — фильтр «Все / Мои / МЦНМО»,
  а не переключение экрана.
- **Раздел верхнего уровня: Планиметрия / Стереометрия** — новое поле
  `geometry_tasks.section` (`planim | stereo`). Для МЦНМО заполняется скриптом
  по фасетам-объектам (куб, пирамида, сфера, двугранный угол…), для своих — по
  теме; дальше ставится в редакторе.
- **Фасеты объект / метод / факт — общая навигация** для обеих областей (свои
  задачи размечаются, см. п. 3).
- Темы/подтемы своих задач остаются, но только как математическое деление
  (сечения, углы, расстояния). Темы-работы уезжают в «Работы» (п. 4).
- Банк по-прежнему не грузится целиком: без раздела/фасета/поиска в области
  «МЦНМО» — подсказка, а не 17 тыс. строк.

### 2. Карточка задачи — одна на весь раздел

Таблица, карточки, «Поиск по смыслу», «Похожие», дубли — всё открывает **одну
боковую панель** (Drawer), без модалки поверх модалки:

- крупный чертёж (стерео — с вращением), условие, ответ, указания, решение
  (+ фото решения), фасеты-чипы, источник/год, сложность;
- действия: **«В подборку»** (с выбором варианта, если работа открыта),
  «Редактировать», «Взять к себе» (копия задачи МЦНМО в свои — чтобы править),
  «Похожие», «Открыть в стерео-/планиметрическом редакторе»;
- ← / → по текущему списку (листать результаты поиска).

Редактирование макета A5 из просмотра убирается — оно принадлежит печати работы.

### 3. Общие фасеты для своих задач

- В редакторе задачи — три мультиселектора фасетов (как фильтр банка).
- Массовая разметка: выделить задачи → «Проставить фасеты».
- **Подсказка фасетов по соседям:** для своей задачи берём k ближайших задач
  МЦНМО (`/geo/similar`) и предлагаем самые частые их фасеты — учитель
  подтверждает галочками.
- Справочник фасетов правится как сейчас (`GeometryTagsModal`), новые
  фасеты своих задач — в тот же `geometry_tags`.

### 4. Подборка → работа с вариантами

- **Подборка** — плашка внизу раздела со счётчиком; живёт между страницами
  раздела (банк, поиск, генератор). Из неё: «Создать работу» / «Добавить в
  работу…».
- **Работа** — новая коллекция `geometry_works` (с `owner`, как
  `geometry_print_tests`):
  - `title`, `class` (number), `note`;
  - `tasks[] → geometry_tasks` — все задачи всех вариантов (для expand и
    обратного поиска «в каких работах задача»);
  - `structure` (json) — `{ variants: [{ number, items: [{ task, layout?,
    points? } | { gen: {…} }] }] }`: порядок, макет A5 **у позиции**
    (по умолчанию — `preview_layout` задачи), позиции из генератора (п. 5).
- **Редактор работы** — колонки «Вариант 1 / 2 / …», строки — позиции.
  Подбор параллели в другой вариант: кнопка у позиции → кандидаты
  `/geo/similar` (как `ParallelVariantsModal` в обычных работах) или
  генератор, если позиция сгенерирована.
- **Печать — шаблоны одной работы**, а не отдельные кнопки:
  «Карточки A5/A4» (сегодняшний `GeometryTaskPreview`), «Рабочий лист с
  клеткой» (`GeometryWorksheetPrint`), «Ответы/решения по вариантам».
- **Перенос старого:** 1 запись `geometry_print_tests` → работа;
  темы-работы → работы (задачи остаются, тему им потом ставим
  математическую). `geometry_print_tests` и «Листы A5» после переноса
  выводим из меню.

### 5. Генератор сечений

По образцу «Функций → задания по графику»: чертёж и ответ даёт ОДНА модель —
стереодвижок `utils/stereo/`.

- Тела: куб, призма, пирамида (что уже есть в `bodies.js`).
- Случайные точки M, P, R на рёбрах/в гранях с «хорошими» долями; задание
  отбраковывается, если сечение вырождено или не того типа (треугольник /
  четырёх- / пяти- / шестиугольник — по сложности).
- Типы: «Постройте сечение» (ответ — чертёж сечения); «Площадь сечения»
  куба/призмы с числами (ответ — число, точная форма); дальше — угол и
  расстояние в кубе (инструменты угла/перпендикуляра уже есть).
- **Построение по шагам** (метод следов) — генерировать журналом операций,
  чтобы решение показывалось по шагам и шло в эфир. Первая версия может
  давать только итоговое сечение, шаги — следующей.
- Логика — чистый модуль (`utils/stereo/sectionTasks.js` или рядом) под
  тестами; ответ сверяется с моделью.
- **Куда сохраняется:** позиция работы вида `{ gen: { type, params, scene } }`
  — банк не засоряется; «Сохранить в банк» — по кнопке. Варианты контрольной
  на сечения собираются генератором автоматически.

### 6. Связи с платформой (без слияния)

- **Журнал класса:** колонка «из геометрической работы»,
  `ref: { type: 'geometry_work', id }` — как листы генераторов (v3.9.240).
- **Уроки/календарь:** прикрепить работу к уроку.
- **Построение по шагам в карточке задачи** и кнопка «В эфир», если чертёж
  задачи сделан в стереоредакторе.
- **Позже:** ссылка ученику без входа (по образцу пособия `/s/<id>`).

## Этапы

1. **Карточка задачи + единый банк** (п. 1–2). БД: одно новое поле `section`
   + скрипт заполнения для МЦНМО. Заодно починить «В геометрию» в
   `TaskEditModal` (грузит все 17,9 тыс. задач и считает код «длина + 1» —
   нужен `api.getNextGeometryCode`).
2. **Подборка и работы с вариантами** (п. 4): миграция `geometry_works`,
   редактор работы, печать шаблонами, перенос `geometry_print_tests` и
   тем-работ.
3. **Общие фасеты** (п. 3): разметка в редакторе, массовая, подсказка по
   соседям.
4. **Генератор сечений** (п. 5): «постройте сечение» → «площадь сечения» →
   шаги построения.
5. **Связи** (п. 6): журнал, уроки, построение по шагам/эфир.
6. Позже — ссылка ученику.

## Открытые вопросы (решить по ходу)

- Число вариантов по умолчанию и нумерация (1/2 или А/Б).
- Привязка работы к классу: число `class` (как `works`) или группа — если
  группа, то по правилу `prev_group` (CLAUDE.md, п. 14).
- Нужен ли лист ответов отдельной страницей или ответы в конце работы.
- Какие фасеты считать «стереометрическими» для заполнения `section` —
  список проверить глазами перед прогоном скрипта.

## Безопасность данных

Все миграции — только добавляющие (новое поле, новая коллекция). Перенос
`geometry_print_tests` и тем-работ — скриптом с dry-run; перед прогоном на ПРОДе
— свежий бэкап VPS и подтверждение пользователя (CLAUDE.md § БД).

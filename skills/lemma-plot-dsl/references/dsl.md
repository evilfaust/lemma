# Справочник DSL блока ```plot

Одна команда на строку. Точка с запятой — тоже разделитель (нужна для inline-формы
в ячейках таблиц), но «;» внутри скобок не режет команду: точку кривой можно
писать по-русски `(-3; 2)`. Строки, начинающиеся с `#`, — комментарии.
Числа принимают десятичную запятую и дроби: `1,5`, `1/2`, минус любой (`−`, `–`).

Содержание:
1. Окно и оформление
2. Кривые по точкам (главное)
3. Производная, первообразная, касательная
4. Разметка на кривой: mark, drop, part, band
5. График по формуле
6. Точки, отрезки, векторы
7. Подписи и засечки
8. Цвета
9. Куда вставлять результат

## 1. Окно и оформление

```
x -4 4            диапазон по оси X (алиас xrange)
y -3 5            диапазон по оси Y (алиас yrange)
grid 1            шаг клетки; grid off — без клетки
size 280          ширина картинки в px (80…900, по умолчанию 280)
axis x y          буквы осей; axis t s — свои
units off         не подписывать единичные отрезки «1»
```

Высота считается сама по пропорциям окна (не больше 320 px). Клетка всегда
квадратная: если по x диапазон шире, чем по y, картинка получится широкой.
Для сканов без клетки стандартная шапка — `grid off` + `units off`.

## 2. Кривые по точкам (главное)

```
spline f (-5 -3) (-3 2) (0 -1) (3 3)
```

`spline` (алиас `curve`) строит гладкую кривую через указанные точки. Имя (`f`,
`g`, `F`, `f'`) нужно, чтобы ссылаться на неё дальше; без имени кривая зовётся
`f`. Точки можно писать и парами чисел без скобок: `spline f -5 -3  -3 2  0 -1`.

**Между соседними точками кривая монотонна** — лишних горбов не будет, но и
y-значения узлов обязаны идти согласованно: на участке от максимума до минимума
они должны строго убывать. Если это нарушить, движок пожалуется или подправит
форму. Нужно не меньше двух точек.

Флаги внутри скобок:

```
(0 0 flat)        f′ = 0 без смены знака — «полочка», стационарная точка
(2 1 slope 1/2)   заданный наклон касательной в этой точке
```

Модификаторы всей кривой (пишутся в конце строки, в любом порядке):

```
color blue        цвет (см. §8)
dash              пунктир
bold              толстая линия
hide              задать кривую, но не рисовать (нужна для ссылок)
from -2 to 3      нарисовать только кусок; можно односторонне: from -2 / to 3
```

## 3. Производная, первообразная, касательная

```
deriv f                график производной f′ (color/dash/bold/from…to)
deriv f'               график второй производной f″
prim F f 0 1           первообразная F кривой f с условием F(0) = 1
prim F f                … без точки: F(левый край) = 0
prim f f' 0 1 hide     функция f как первообразная нарисованной f′, не рисуя её
tangent 1 f            касательная к f в точке x = 1 (можно from…to)
```

Штрих в имени кривой значим. `spline f' (…)` означает «точки задают ПРОИЗВОДНУЮ»:
нарисована f′, а сама f получается первообразной — так собираются задания
«на рисунке изображён график f′(x)». После этого `mark -2 f` поставит точку на
самой функции, даже если она не нарисована.

Ссылки разрешаются после разбора всех строк: `deriv f` может стоять выше
`spline f`.

## 4. Разметка на кривой: mark, drop, part, band

```
mark -3 f              точка на графике f в x = −3
mark 0 f' open big     вид: fill | open | cross | plus; размер: small | normal | big
drop -3 f              пунктирная выноска от оси x до графика
drop -3 f solid        сплошная выноска
part f -3 1 color green bold
                       кусок уже нарисованной кривой поверх неё другим цветом —
                       так показывают промежутки возрастания/убывания или знака
band -3 3              отрезок на оси x (по умолчанию красный, как на плакатах)
band -3 3 color ink
```

`part` без указания цвета рисуется красным. Границы можно задать и через
модификатор: `part f from -3 to 1 color red bold`.

## 5. График по формуле

```
f x^2-4                       график функции (алиасы plot, func)
f sin(x) color blue from -pi to pi
f 1/x dash
```

Поддержаны: `+ - * / ^`, скобки, неявное умножение (`2x`, `3(x+1)`), константы
`pi`, `e`, функции `sqrt cbrt abs sin cos tan tg ctg asin acos atan arctg ln lg
log2 log10 exp floor ceil round sign`, двухаргументные `log(основание, аргумент)`,
`pow min max root(n, x)`. Переменная только `x`. Модификаторы — те же
(`color`, `dash`, `bold`, `from…to`).

Формулу берите, когда на картинке действительно график формулы (парабола,
синусоида, гипербола) — линия получится точной. Для «рисованных» графиков из
заданий на производную формула не нужна и вредна: экстремумы уедут.

## 6. Точки, отрезки, векторы

```
point 1 3              точка на плоскости; вид fill | open | cross | plus,
point 2 -1 open small  размер small | normal | big, можно color
seg 0 0 2 3 dash       отрезок между двумя точками
vec a 1 4 3 1          вектор из (1; 4) в (3; 1) с подписью a
vec b 2 3              вектор из начала координат в (2; 3)
vec 1 1 4 2 color blue вектор без подписи
```

У вектора подпись по умолчанию слева от стрелки; `side right` — справа.

## 7. Подписи и засечки

```
label 2 3 A                    подпись у точки (2; 3)
label 3.5 3 y = f(x) at ne     сторона: ne n nw w sw s se e (или up/down/left/right)
label -2 1 M_1 at nw 2         вдвое дальше от точки — когда подпись лезет на график
xtick -5                       засечка с подписью «−5» на оси X
xtick 1.57 \frac{\pi}{2}       своя подпись
xtick 3 x_1 bold               жирная подпись
ytick 3 три
```

Подписи набираются как формулы — подмножеством LaTeX: индексы и степени
(`x_1`, `y^2`), дроби `\frac{a}{b}`, корни `\sqrt{2}`, греческие буквы,
знаки `\le \pm \to \infty`, штрих `f'(x)`, `\text{…}`, `\vec{a}`. Обычные слова
проходят как есть: латиница — курсивом, кириллица — прямым шрифтом.
Последнее слово `bold` делает подпись жирной.

Подписанные точки на оси из сканов (x₁, x₂, …) — это `xtick 2 x_1`, отдельная
`point` для них не нужна: засечку движок рисует сам.

## 8. Цвета

`ink` (по умолчанию, почти чёрный), `blue`, `red`, `green`, `orange`, `violet`,
`gray`. Всё, что не названо цветом, печатается чёрным — чертёж рассчитан на
Ч/Б печать, цвет включается осознанно (выделить кусок, отличить две кривые).

```

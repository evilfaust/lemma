# Графики функций и векторы — блок ```plot

Редактор «График» / «Векторы» (PlotModal) и блок ```plot (алиас ```vectors).
Ниже — полный справочник команд, затем готовые рецепты типовых картинок ЕГЭ.


Одна команда на строку. Точка с запятой — тоже разделитель (нужна для inline-формы
в ячейках таблиц), но «;» внутри скобок не режет команду: точку кривой можно
писать по-русски `(-3; 2)`. Строки, начинающиеся с `#`, — комментарии.
Числа принимают десятичную запятую и дроби: `1,5`, `1/2`, минус любой (`−`, `–`).

Содержание:
1. Окно и оформление
2. Кривые по точкам (главное)
3. Производная, первообразная, касательная
4. Разметка на кривой: mark, drop, part, band
5. График по формуле
6. Точки, отрезки, векторы
7. Подписи и засечки
8. Цвета
9. Куда вставлять результат

## 1. Окно и оформление

```
x -4 4            диапазон по оси X (алиас xrange)
y -3 5            диапазон по оси Y (алиас yrange)
grid 1            шаг клетки; grid off — без клетки
size 280          ширина картинки в px (80…900, по умолчанию 280)
axis x y          буквы осей; axis t s — свои
units off         не подписывать единичные отрезки «1»
```

Высота считается сама по пропорциям окна (не больше 320 px). Клетка всегда
квадратная: если по x диапазон шире, чем по y, картинка получится широкой.
Для сканов без клетки стандартная шапка — `grid off` + `units off`.

## 2. Кривые по точкам (главное)

```
spline f (-5 -3) (-3 2) (0 -1) (3 3)
```

`spline` (алиас `curve`) строит гладкую кривую через указанные точки. Имя (`f`,
`g`, `F`, `f'`) нужно, чтобы ссылаться на неё дальше; без имени кривая зовётся
`f`. Точки можно писать и парами чисел без скобок: `spline f -5 -3  -3 2  0 -1`.

**Между соседними точками кривая монотонна** — лишних горбов не будет, но и
y-значения узлов обязаны идти согласованно: на участке от максимума до минимума
они должны строго убывать. Если это нарушить, движок пожалуется или подправит
форму. Нужно не меньше двух точек.

Флаги внутри скобок:

```
(0 0 flat)        f′ = 0 без смены знака — «полочка», стационарная точка
(2 1 slope 1/2)   заданный наклон касательной в этой точке
```

Модификаторы всей кривой (пишутся в конце строки, в любом порядке):

```
color blue        цвет (см. §8)
dash              пунктир
bold              толстая линия
hide              задать кривую, но не рисовать (нужна для ссылок)
from -2 to 3      нарисовать только кусок; можно односторонне: from -2 / to 3
```

## 3. Производная, первообразная, касательная

```
deriv f                график производной f′ (color/dash/bold/from…to)
deriv f'               график второй производной f″
prim F f 0 1           первообразная F кривой f с условием F(0) = 1
prim F f                … без точки: F(левый край) = 0
prim f f' 0 1 hide     функция f как первообразная нарисованной f′, не рисуя её
tangent 1 f            касательная к f в точке x = 1 (можно from…to)
```

Штрих в имени кривой значим. `spline f' (…)` означает «точки задают ПРОИЗВОДНУЮ»:
нарисована f′, а сама f получается первообразной — так собираются задания
«на рисунке изображён график f′(x)». После этого `mark -2 f` поставит точку на
самой функции, даже если она не нарисована.

Ссылки разрешаются после разбора всех строк: `deriv f` может стоять выше
`spline f`.

## 4. Разметка на кривой: mark, drop, part, band

```
mark -3 f              точка на графике f в x = −3
mark 0 f' open big     вид: fill | open | cross | plus; размер: small | normal | big
drop -3 f              пунктирная выноска от оси x до графика
drop -3 f solid        сплошная выноска
part f -3 1 color green bold
                       кусок уже нарисованной кривой поверх неё другим цветом —
                       так показывают промежутки возрастания/убывания или знака
band -3 3              отрезок на оси x (по умолчанию красный, как на плакатах)
band -3 3 color ink
```

`part` без указания цвета рисуется красным. Границы можно задать и через
модификатор: `part f from -3 to 1 color red bold`.

## 5. График по формуле

```
f x^2-4                       график функции (алиасы plot, func)
f sin(x) color blue from -pi to pi
f 1/x dash
```

Поддержаны: `+ - * / ^`, скобки, неявное умножение (`2x`, `3(x+1)`), константы
`pi`, `e`, функции `sqrt cbrt abs sin cos tan tg ctg asin acos atan arctg ln lg
log2 log10 exp floor ceil round sign`, двухаргументные `log(основание, аргумент)`,
`pow min max root(n, x)`. Переменная только `x`. Модификаторы — те же
(`color`, `dash`, `bold`, `from…to`).

Формулу берите, когда на картинке действительно график формулы (парабола,
синусоида, гипербола) — линия получится точной. Для «рисованных» графиков из
заданий на производную формула не нужна и вредна: экстремумы уедут.

## 6. Точки, отрезки, векторы

```
point 1 3              точка на плоскости; вид fill | open | cross | plus,
point 2 -1 open small  размер small | normal | big, можно color
seg 0 0 2 3 dash       отрезок между двумя точками
vec a 1 4 3 1          вектор из (1; 4) в (3; 1) с подписью a
vec b 2 3              вектор из начала координат в (2; 3)
vec 1 1 4 2 color blue вектор без подписи
```

У вектора подпись по умолчанию слева от стрелки; `side right` — справа.

## 7. Подписи и засечки

```
label 2 3 A                    подпись у точки (2; 3)
label 3.5 3 y = f(x) at ne     сторона: ne n nw w sw s se e (или up/down/left/right)
label -2 1 M_1 at nw 2         вдвое дальше от точки — когда подпись лезет на график
xtick -5                       засечка с подписью «−5» на оси X
xtick 1.57 \frac{\pi}{2}       своя подпись
xtick 3 x_1 bold               жирная подпись
ytick 3 три
```

Подписи набираются как формулы — подмножеством LaTeX: индексы и степени
(`x_1`, `y^2`), дроби `\frac{a}{b}`, корни `\sqrt{2}`, греческие буквы,
знаки `\le \pm \to \infty`, штрих `f'(x)`, `\text{…}`, `\vec{a}`. Обычные слова
проходят как есть: латиница — курсивом, кириллица — прямым шрифтом.
Последнее слово `bold` делает подпись жирной.

Подписанные точки на оси из сканов (x₁, x₂, …) — это `xtick 2 x_1`, отдельная
`point` для них не нужна: засечку движок рисует сам.

## 8. Цвета

`ink` (по умолчанию, почти чёрный), `blue`, `red`, `green`, `orange`, `violet`,
`gray`. Всё, что не названо цветом, печатается чёрным — чертёж рассчитан на
Ч/Б печать, цвет включается осознанно (выделить кусок, отличить две кривые).

## 9. Куда вставлять результат

В условие задачи, решение, теорию — fenced-блоком:

````
```plot
x -5 5
spline f (-4 2) (0 -2) (4 2)
```
````

В ячейку markdown-таблицы (где fenced-блок не работает) — inline-формой с «;»:

```
`plot: x -3 3; grid off; f x^2 color blue`
```

Алиас блока — ```vectors (то же самое, удобно, когда на чертеже только векторы).


# Рецепты

## Рецепт 1. Скан без клетки: график f и подписанные точки x₁…x₈

Самый частый случай в сборниках (Школково, «Решу ЕГЭ»): нарисованы только оси,
на оси x — выколотые кружочки с подписями x₁, x₂, …, от некоторых идёт
вертикальный пунктир к жирной точке на кривой, а часть кривой выделена цветом.

Как читать:
- **пунктир от подписанной точки оси к жирной точке на кривой** — значит
  абсцисса этого экстремума и есть подписанная точка: ставьте узел ровно в этом x;
- **подписанная точка без пунктира** — обычно ноль функции (кривая пересекает
  ось) или точка, о которой спрашивают в условии; узел там нужен, только если
  пересечение должно быть точно в этом месте;
- **цветной (розовый) кусок** — промежуток убывания (реже: где f < 0). Он идёт
  от максимума до следующего минимума — это `part`;
- ординаты произвольны: клетки нет, важны только порядок и соотношение высот.

```plot
x -0,5 15
y -5 5
grid off
units off
spline f (0 -4) (1 4) (3 -2,5) (4,5 1) (6 -0,7) (8 2,2) (10,5 -0,5) (11,5 0,3) (13 -4) (14,3 4,5)
label 10 3,5 y = f(x)
xtick 1 x_1
xtick 2 x_2
xtick 3 x_3
xtick 4,5 x_4
xtick 6 x_5
xtick 8 x_6
xtick 11,5 x_7
xtick 13 x_8
mark 1 f
drop 1 f
mark 3 f
drop 3 f
part f 1 3 color red bold
part f 4,5 6 color red bold
part f 8 10,5 color red bold
part f 11,5 13 color red bold
```

Узлы чередуются по высоте (−5 ↑ 4 ↓ −2,5 ↑ 1 ↓ …) — это и есть список
экстремумов слева направо. Крайние узлы вынесены за края подписей: на скане
кривая уходит за рисунок, и обрыв на границе окна выглядит так же.

## Рецепт 2. «На рисунке изображён график f′(x)»

Точки задают производную, а сама функция нужна для ответов про максимумы и
возрастание. Пишите имя со штрихом и добавьте скрытую первообразную:

```plot
x -5 5
y -3 3
grid 1
spline f' (-4 2) (-2 0) (0 -2) (2 0) (4 2)
prim f f' -4 1 hide
label 3 2,4 y = f'(x)
xtick -2
xtick 2
```

Тогда `mark -2 f` поставит точку на самой функции (её не видно), а нули
нарисованной кривой со сменой + на − — это точки максимума f.

Зеркальный случай — на картинке график f, а в задаче спрашивают про f′:
нарисуйте `spline f (…)` и добавьте `deriv f color blue dash`, если вторая
кривая действительно есть на исходнике.

## Рецепт 3. Касательная и значение производной

Картинка: график, к нему в точке приложена прямая, часто с отмеченным
треугольником наклона.

```plot
x -6 6
y -5 5
grid 1
spline f (-5 -3) (-2 0 slope 1,5) (0 3) (2 1) (5 4)
tangent -2 f color blue
mark -2 f
drop -2 f
xtick -2 x_0
```

Флаг `slope K` внутри узла задаёт наклон касательной — берите его с картинки по
клеткам (подъём/пробег). Если касательная проведена не в экстремуме и наклон с
рисунка не читается точно, поставьте узел в точку касания и подберите `slope`
так, чтобы прямая легла как на оригинале.

## Рецепт 4. Первообразная и площадь под графиком

```plot
x -3 5
y -2 6
grid 1
spline f (-2 0) (0 2) (2 0) (4 -1,5) hide
prim F f -2 0
label -2,5 4,5 y = F(x) at se
band 0 2
drop 0 F
drop 2 F
mark 0 F
mark 2 F
xtick 0
xtick 2
```

`band a b` рисует жирный отрезок на оси — то самое «от a до b», о котором
спрашивает условие.

## Рецепт 5. График по формуле (парабола, синусоида, гипербола)

Если на картинке честный график формулы, не собирайте его точками — движок
нарисует точнее:

```plot
x -4 4
y -5 5
grid 1
f x^2-3 color blue
f 2x+1 dash
point -1 -2 open
label -1 -2 A at sw
```

Синусоида с осью в долях π:

```plot
x -3,2 6,5
y -2 2
grid off
f sin(x) color blue
xtick 3,14 \pi
xtick 6,28 2\pi
xtick 1,57 \frac{\pi}{2}
```

## Рецепт 6. Соответствие «точка ↔ значение производной»

Четыре точки на кривой с касательными, ответ — четыре цифры:

```plot
x -6 6
y -4 4
grid 1
spline f (-5 -2) (-3,5 2 slope 0) (-1 -1 slope 0) (1 1 slope 1) (3 3 slope 0,5) (5 -1)
mark -3,5 f
mark -1 f
mark 1 f
mark 3 f
tangent -3,5 f color gray
tangent -1 f color gray
tangent 1 f color gray
tangent 3 f color gray
label -3,5 2 A at n
label -1 -1 B at s
label 1 1 C at nw
label 3 3 D at ne
```

## Рецепт 7. Векторы и точки на плоскости

```plot
x -1 6
y -1 5
grid 1
vec a 0 0 4 2
vec b 4 2 1 4 color blue
point 4 2 fill
label 4 2 M at se
seg 0 0 1 4 dash
```

## Частые ошибки

- **Лишний узел портит ответ.** Каждый узел, нарушающий монотонность участка,
  создаёт экстремум. Ставьте узлы только там, где кривая действительно
  поворачивает или обязана пройти точно.
- **Формула вместо точек.** Подобранный многочлен даёт экстремумы в
  некрасивых местах, и ответ задачи разъезжается с чертежом.
- **Цвет ради красоты.** Чертежи печатаются в Ч/Б: цветом выделяют только то,
  что выделено на оригинале и несёт смысл.
- **Подписи поверх кривой.** Если `label` накрывает график, сдвиньте её:
  `at nw 2` (вдвое дальше от точки) или выберите другую сторону.
- **Слишком узкое окно.** Оставьте по краям запас, иначе экстремум у границы
  выглядит как обрыв.
- **`slope` в узле-экстремуме.** В максимуме и минимуме касательная
  горизонтальна, любой другой наклон движок проигнорирует. Наклон задают в
  узле на монотонном участке — там, где на картинке и проведена касательная.
- **Первообразная вылезла за окно.** `prim` накапливает площадь, и её значения
  легко уходят за `y c d`. Прикиньте площадь под f на всём промежутке и
  расширьте окно по вертикали.
- **Подписи на оси слиплись.** Если на скане x₁…x₈ стоят кучно, разнесите их в
  своих координатах — смысл задачи от этого не меняется, а чертёж читается.

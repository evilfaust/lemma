# Диаграммы, числовые прямые, клетка

Содержание: ```chart (график по таблице значений и столбики) · ```numline
(числовая прямая) · ```grid (место для решения).

---

## ```chart — график или диаграмма по таблице значений

Кнопка «Диаграмма» (ChartModal). Для задач базы №3/№7 «Решу ЕГЭ»: осадки по
дням, температура по часам, давление, скорость, продажи по месяцам. У каждой
оси свой масштаб, шкала «4,0», подписи осей словами. Однострочник:
`` `chart: x 1 5 step 1; y 0 10 step 2; values 3 5 4 8 6` ``.

### Команды

| Команда | Что задаёт |
|---|---|
| `x 8 24 step 1` | окно по x и шаг клетки; `label 2` — подписывать каждые 2 |
| `y 0 4,5 step 0,5 decimals 1` | окно по y, шаг; `decimals 1` — подписи «4,0», «0,5»; `label 1` — подписывать каждое 1 |
| `xtitle Число месяца` | подпись под осью x |
| `ytitle Количество осадков, мм` | подпись оси y (вертикально) |
| `xunit ч` / `yunit °C` | маленькая единица у конца оси |
| `values 4 1,5 0,25 …` | линия: значения подряд с x = начало окна, шаг — `step` оси x |
| `line (8; 4) (9; 1,5) …` | линия по точкам (x; y) — когда x идут неравномерно |
| `bar 30 25 35 …` | столбики, по одному на категорию |
| `labels янв фев мар` | подписи столбиков (подпись с пробелами — разделять «\|»); у линии — подписи засечек x вместо чисел, идут по кругу |
| `groups 4 апреля \| 5 апреля` | строка под подписями оси x (даты, годы): ось делится поровну; свой отрезок — `(0; 24) 4 апреля \| (24; 48) …`, у столбиков — номера столбиков `(1; 4) 2025` |
| `size 480 300` | холст в px (S 280×175, M 340×210 по умолчанию, L 420×260) |
| `font 1,2` | масштаб шрифта |

Модификаторы линии (`values` и `line`): `color orange` (ink, orange, blue,
green, red, violet, gray), `smooth` — плавная кривая, `nodots` — без точек,
`dash` — пунктир. Линий может быть несколько (две температуры — две `line`).

Правило `values`: значений должно быть (max − min) / step + 1 — по одному на
каждое деление оси x. Иначе линия оборвётся или сдвинется.

### Примеры

Осадки по дням (жирные точки, соединённые отрезками, — классика базы №3):

```chart
x 8 24 step 1
y 0 4,5 step 0,5 decimals 1
xtitle Число месяца
ytitle Количество осадков, мм
values 4 1,5 0,25 1,5 4 0 3 1,5 1,75 0,5 1 0 0,5 0,8 0 0 0,5
```

Температура по часам — плавная кривая:

```chart
x 0 24 step 3
y -6 6 step 2
yunit °C
xunit ч
line (0; -4) (3; -6) (6; -2) (9; 2) (12; 6) (15; 4) (18; 0) (21; -2) (24; -4) smooth color blue
```

Давление за трое суток — частая сетка, подписи через одну:

```chart
x 0 14 step 1
y 750 762 step 1 label 2
ytitle Атмосферное давление, мм рт. ст.
line (0; 761) (1,5; 760,3) (2,5; 758,9) (3,5; 757,5) (4,5; 756) (5,5; 754) (7; 753) (8; 754,2) (9; 755) (10; 754,5) (12; 753,5) (13; 751,5) (14; 751) color orange smooth nodots
size 480 390
```

Столбчатая диаграмма по месяцам:

```chart
y 0 80 step 10 label 20
ytitle Осадки, мм
bar 30 25 35 40 50 70
labels янв фев мар апр май июн
```

Скорость автомобиля — ломаная без точек:

```chart
x 0 5 step 0,5 label 1
y 0 100 step 20 label 20
xtitle t, час
ytitle v, км/ч
line (0; 0) (0,5; 40) (1; 40) (1,25; 20) (1,75; 20) (2; 0) (2,5; 0) (3; 60) (3,5; 80) (4; 40) (5; 0) color orange nodots
size 480 300
```

Давление по суткам — время под осью, даты строкой ниже (как в базе №3):

```chart
x 0 72 step 6
y 752 766 step 2
values 755 758 758 757 754 756 759 760 759 765 765 762 760 color orange
labels 00:00 06:00 12:00 18:00
groups 4 апреля | 5 апреля | 6 апреля
```

### Снимаем с картинки

1. Окно и шаг — по сетке исходника; если подписаны не все деления, `label N`.
2. Подписи вида «4,0» на оси y → `decimals 1`.
3. Точки на целых делениях подряд → `values`; иначе → `line (x; y)`.
4. Под осью время «06:00» и даты ниже → `labels 00:00 06:00 12:00 18:00` +
   `groups 4 апреля | 5 апреля | …` (числа x — часы от начала: 0, 6, …, 72).
5. Жирные точки с отрезками — по умолчанию; плавная кривая без точек —
   `smooth nodots`.

## ```numline — числовая прямая

Кнопка «Числовая прямая» (NumberLineModal). Решения неравенств, промежутки,
точки с буквами. Рисунок строго чёрно-белый. Однострочник:
`` `numline: domain -4 4; ray left -1 open` ``.

### Режим «Неравенства» (штриховка)

| Команда | Что рисует |
|---|---|
| `domain -3 5` | видимый диапазон оси (по умолчанию 0…5) |
| `seg -1 3 fill open` | отрезок с заштриховкой; концы `fill` (закрашен, нестрогое) / `open` (выколот, строгое) — по одному слову на каждый конец |
| `ray right 2 open` | луч вправо от 2 (`left` — влево); конец `open`/`fill` |
| `point 1 fill` | отдельная точка (`open` — выколотая) |
| `all` | заштриховать всю прямую (решение — любое число) |
| `tick 1.41 \sqrt{2}` | подпись под осью (формула LaTeX без `$`; `1/2` станет дробью) |
| `nolabels` | не подписывать числа под осью |
| `axis t` | буква оси (по умолчанию x) |

Числа под точками ставятся сами (по координатам концов), подпись-формулу
задают `tick`: координата — для места, текст — для подписи
(`tick 3.14 \pi`). Бесконечность для `seg` — `inf` / `-inf`.

### Режим «Точки на прямой» (засечки и буквы)

| Команда | Что рисует |
|---|---|
| `scale -3 3 1` | засечки от −3 до 3 с шагом 1, с числами |
| `mark A -2` | буква над точкой (`mark A_1 2`, `bold` в конце — жирная) |

`scale`/`mark` не смешивать со штриховкой (`seg`, `ray`, `point`) в одном
блоке. Без `scale` — голая ось: `domain` + `mark` + `nolabels`.

### Примеры

Решение неравенства −1 ≤ x < 3:

```numline
domain -3 5
seg -1 3 fill open
```

Объединение лучей x < −2 или x ≥ 1:

```numline
domain -5 4
ray left -2 open
ray right 1 fill
```

Метод интервалов с выколотой точкой внутри:

```numline
domain -4 6
seg -2 4 fill fill
point 1 open
```

Подпись-корень:

```numline
domain 0 3
point 1.41 fill
tick 1.41 \sqrt{2}
```

Точки с буквами на голой оси («какая точка соответствует числу…»):

```numline
domain -3 3
mark A -2
mark B 1
mark C 2.5
nolabels
```

Шкала с засечками:

```numline
scale -3 3 1
mark P -1.5
mark Q 2
```

Варианты ответа в таблице (задания «укажите решение неравенства»):

```
{галерея}

| 1) `numline: domain -4 4; ray left -1 open` | 2) `numline: domain -4 4; ray right -1 fill` |
| --- | --- |
| 3) `numline: domain -4 4; seg -1 2 open open` | 4) `numline: domain -4 4; all` |
```

## ```grid — место для решения

Кнопка «Клетка». Тетрадная клетка 5 мм, линейка или чистое поле — прямо в
условии или в ячейке таблицы «задание | решение». Одна строка, параметры
через пробел.

| Запись | Что рисует |
|---|---|
| `x6` (или `6`) | 6 клеток в высоту, ширина — на всю строку/ячейку |
| `12x5` | 12 × 5 клеток |
| `10x6 cell 7` | клетка 7 мм |
| `x4 lines` | в линейку (шаг 8 мм) |
| `x4 blank` | пустое поле в рамке |
| `x6 noframe` | без рамки |

```grid
x6
```

```grid
x4 lines
```

Задание и место для решения в таблице:

```
| Задание | Решение |
| --- | --- |
| $2x = 8$ | `grid: x3` |
| $3x - 1 = 5$ | `grid: x3` |
```

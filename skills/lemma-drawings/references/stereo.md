# Стереометрия — блок ```stereo

Редактор «Стерео» (`/app/geometry/stereo`) и блок ```stereo в любом поле.
Чертёж = **тело + журнал операций**. Первая строка — тело (или `пространство`),
дальше построения по одному на строку. Невидимые линии движок сам рисует
пунктиром, проекция параллельная («как в учебнике»). В теории блок можно
крутить и листать по шагам; в печати — всегда картинка.

Однострочник для ячейки таблицы: `` `stereo: куб 4; сечение AB1D1; вид 30 20` ``.

Содержание: тела · служебные строки · точки · прямые · перпендикуляры ·
плоскости и сечения · углы · длины · жидкость · оформление · без тела ·
примеры · ошибки.

## Тело — первая строка

Вершины: основание A, B, C, D… против часовой стрелки (A — спереди слева),
верхнее основание — те же буквы с 1 (A1, B1…), вершина пирамиды — буква в
команде.

| Команда | Тело |
|---|---|
| `куб 4` | ABCDA1B1C1D1, ребро 4 |
| `параллелепипед 4 3 2` | прямоугольный: AB = 4, AD = 3, AA1 = 2 |
| `призма 3 4 5` | правильная: сторон основания (3–8), ребро основания, высота → ABCA1B1C1 |
| `призма 6 2 4` | правильная шестиугольная ABCDEFA1…F1 |
| `пирамида 4 4 5 S` | правильная: сторон основания, ребро, высота, имя вершины → SABCD |
| `пирамида 3 4 5 D` | правильная треугольная DABC |
| `тетраэдр 4 D` | правильный тетраэдр ABCD |
| `наклонная призма 3 4 5` | боковое ребро под 60°; точнее — `призма 3 4 5 наклон 70 влево` (вправо, влево, вперёд, назад) |
| `наклонный параллелепипед 4 3 5 параллелограмм` | основание: прямоугольник (по умолчанию), параллелограмм, ромб |
| `призма 4 6 4 трапеция` | основание: произвольное, прямоугольный, равнобедренный, прямоугольник, параллелограмм, ромб, трапеция (AD ∥ BC) |
| `пирамида 4 4 5 S над A` | вершина над A — ребро SA ⊥ основанию; `над AB` — над серединой AB |
| `пирамида 4 4 5 S произвольное` | произвольный четырёхугольник в основании |
| `тетраэдр 4 3 D произвольный` | произвольный тетраэдр DABC: ребро AB, высота, имя вершины |
| `усечённая пирамида 4 4 2 0,5` | сторон, ребро нижнего основания, высота, во сколько раз верх меньше |
| `призма основание (0 0) (4 0) (5 3) (1 3) h=4` | своё основание по координатам (выпуклое) |
| `октаэдр 4` | правильный октаэдр ABCDEF (ABCD — «экватор», E сверху, F снизу) |
| `куб 4 с пирамидой 2` | к кубу сверху приклеена пирамида высотой 2 (вершина S) |
| `куб 4 без вершин 1` | от каждой вершины по рёбрам отрезано по 1 (буквы не ставятся) |
| `многогранник (0 0 0) (4 0 0) (4 4 0) (0 4 0) (2 2 3)` | свой выпуклый многогранник по точкам (x y z; z — вверх) |
| `цилиндр 2 5` | цилиндр: радиус, высота |
| `конус 2 4` | конус: радиус, высота |
| `усечённый конус 3 1,5 4` | радиусы оснований, высота |
| `шар 2` | шар радиуса 2 |
| `конус 2 4 с буквами` | подписать O (центр основания), S, A (у цилиндра — O, O1, A, A1) |
| `ступенчатый многогранник (0 0 0 4 3 1) (0 0 1 2 3 2)` | «все двугранные углы прямые»: блоки (угол x y z, размеры по x y z) |
| `ступенчатый многогранник (0 0 0 4 4 4) минус (2 0 2 2 2 2)` | из блока вырезан блок |
| `пространство` | без тела: дальше точки по координатам и листы-плоскости |

Модификаторы к телу (той же строкой): `без букв` — без подписей вершин;
`по часовой` — буквы основания по часовой (A — спереди слева, B — сзади
слева); `каркас` — первое тело прозрачное для вписанного.

Размеры тел можно задавать точно по условию: `2√3`, `2*sqrt(3)`,
`√(5/2)`, `(1+√5)/2`, `π` (или `pi`). Разрешены `+`, `-`, `*`, `/`, `^`
и скобки. В строке тела выражение пишется без пробелов; размеры должны
быть положительными. Исходная запись сохраняется при редактировании.
Например, цилиндр радиуса $2\sqrt{3}$ и высоты 3: `цилиндр 2√3 3`.

## Служебные строки

| Строка | Что делает |
|---|---|
| `вершины KLMNK1L1M1N1` | свои имена вершин — сразу после тела, столько же, сколько вершин |
| `и шар 2` | ещё одно тело на чертеже (после `куб 4 каркас`): по умолчанию с общим центром; `справа`, `слева`, `сзади`, `сверху`, `сдвиг x y z` |
| `вид 30 20 1,2` | ракурс: поворот, наклон (90 — сверху), масштаб; обычно не нужен |
| `размер 400 300` | ширина и высота рисунка |
| `цвет` | цветной чертёж (без строки — чёрно-белый) |
| `статично` | в теории не крутится |
| `M на AA1 1:2 // делим ребро` | после `//` — подпись шага |

## Точки

| Команда | Что строит |
|---|---|
| `M на AA1 1:2` | точка на ребре/отрезке: AM : MA1 = 1 : 2 |
| `K на AB 0,25` | доля от первой точки (0,5 — середина; больше 1 — на продолжении) |
| `O = середина AC1` | середина (без имени — `середина AC1`) |
| `X = MN ∩ AC` | пересечение двух прямых (можно `MN x AC`) |
| `X = MN ∩ (ABC)` | точка, где прямая протыкает плоскость (след) |
| `след MN ABCD` | то же |
| `K в грани ABB1A1 0,3 0,4` | точка внутри грани по двум долям |
| `K на окружности O 120` | точка на окружности тела вращения по углу |
| `K на поверхности O 30 0,5` | на боковой поверхности цилиндра/конуса: угол и доля высоты |
| `показать O` | подписать точку, которую тело прячет (центр цилиндра) |

## Прямые и отрезки

| Команда | Что строит |
|---|---|
| `MN` | отрезок (невидимые части — пунктиром сами) |
| `прямая MN` | прямая |
| `прямая K \|\| AB` | через K параллельно AB |
| `K на (P\|\|AB) 0,3` | на параллельную в других командах ссылаются `(P\|\|AB)` |

## Перпендикуляры

| Команда | Что строит |
|---|---|
| `H = M ⊥ AB` | из M на прямую AB: основание H, отрезок MH, знак прямого угла |
| `H = M ⊥ (ABC)` | из M на плоскость ABC: основание H и отрезок MH |
| `O = S ⊥ (ABC)` | высота пирамиды (основание — в центре, внутри тела пунктиром) |
| `перпендикуляр из M на ABC` | то же словами: две буквы в конце — к прямой, три — к плоскости |
| `M ⊥ AC в ABC` | M лежит на AC — перпендикуляр к AC через M в плоскости ABC |
| `сечение M ⊥ BD1` | сечение плоскостью через M перпендикулярно BD1 |
| `плоскость AB ⊥ (A1DC)` | плоскость через AB перпендикулярно плоскости A1DC |

## Плоскости и сечения

| Команда | Что строит |
|---|---|
| `сечение MNB` | сечение тела плоскостью через три точки (многоугольник сечения строится сам) |
| `плоскость AA1C` | полупрозрачная плоскость через три точки |
| `грань ABCD` | выделить грань |
| `заливка KLMN` | закрасить многоугольник (точки в одной плоскости) |

## Углы

| Команда | Что рисует |
|---|---|
| `угол ABD α` | отметка ∠ABD (вершина — средняя буква): дуга и подпись |
| `угол A1BD 2 дуги` | 2–3 дуги — равные углы; 90° — знак прямого угла |
| `угол AC BD` | угол между пересекающимися прямыми |
| `угол A1C (ABC)` | угол между прямой и плоскостью: перпендикуляр, проекция, дуга |
| `угол между BD1 и (ABB1)` | то же словами |

## Длины на рёбрах

| Команда | Что рисует |
|---|---|
| `AB = 4` | подпись длины у середины отрезка (отрезка нет — дорисуется) |
| `подпись SO h` | то же: любая подпись — 4, 2,5, √17, h, a√3 |
| `стрелка AA1 h` | размерная стрелка рядом с отрезком (высота воды у аквариума) |
| `AB = \frac{a}{2}` | подписи — формулы LaTeX без долларов: `\frac{a}{2}` или `a/2` — дробью столбиком, `\sqrt{3}`, `a_1` |
| `текст у S вершина` | надпись рядом с точкой (формулой, как подписи) |
| `текст (0; 0; 3) V = \frac{1}{3}Sh` | надпись в точке пространства; начало координат — центр тела, z вверх |

## Жидкость в сосуде

| Команда | Что рисует |
|---|---|
| `уровень 3` | жидкость до высоты 3 от дна (голубым, в печати — серым) |
| `уровень 60%` | доля высоты (можно `уровень 3/5`) |

## Оформление

| Команда | Что делает |
|---|---|
| `цвет MNB красный` | точки: красный, синий, зелёный, оранжевый, фиолетовый, голубой, розовый, жёлтый, коричневый, серый |
| `цвет прямой AB синий` | прямая целиком |
| `цвет отрезка AM зелёный` | кусок между двумя точками |
| `цвет сечения MNB зелёный` | заливка и контур сечения через эти точки |
| `скрыть O` | убрать точку с чертежа (построения через неё остаются) |
| `скрыть отрезок AM` | убрать кусок прямой |
| `скрыть прямую AB` | убрать прямую целиком |

Переименовать точку можно только в редакторе (двойной клик); в блоке свои
имена вершин задаёт строка `вершины …`, а свои точки просто называй сразу
нужной буквой.

## Без тела (`пространство`)

| Команда | Что строит |
|---|---|
| `A = (0; 0; -2)` | точка по координатам (x; y; z), z — вверх |
| `плоскость ABC` | плоскость-лист через три точки |
| `лист α через M` | непрозрачный горизонтальный лист через M: всё под ним — пунктиром |
| `X = PQ ∩ (α)` | на лист ссылаются по букве |

## Примеры

Куб, точки на рёбрах (в условии сечение НЕ рисуем — его строит ученик):

```stereo
куб 4
M = середина AA1
N на CC1 1:3
```

То же в решении — с сечением в цвете:

```stereo
куб 4
M = середина AA1
N на CC1 1:3
сечение MNB
цвет
цвет сечения MNB зелёный
```

Правильная четырёхугольная пирамида с высотой:

```stereo
пирамида 4 4 5 S
O = S ⊥ (ABC)
подпись SO h
AB = 4
```

Правильная треугольная призма, точка на боковом ребре:

```stereo
призма 3 4 5
M = середина BB1
A1M
```

Угол между диагональю куба и основанием:

```stereo
куб 4
AC1
угол A1C (ABC)
```

Прямоугольный параллелепипед с диагональю и подписями рёбер:

```stereo
параллелепипед 4 3 2
AC1
AB = 4
AD = 3
AA1 = 2
```

Куб со своими буквами:

```stereo
куб 4
вершины KLMNK1L1M1N1
KM1
```

Аквариум с водой (база, первая часть):

```stereo
параллелепипед 6 3 4
уровень 3
стрелка AA1 h
```

Цилиндр и конус:

```stereo
цилиндр 2 5 с буквами
```

```stereo
конус 2 4 с буквами
```

Шар, вписанный в куб:

```stereo
куб 4 каркас
и шар 2
```

Ступенчатый многогранник:

```stereo
ступенчатый многогранник (0 0 0 4 4 4) минус (2 0 2 2 2 2)
```

Пирамида с ребром, перпендикулярным основанию:

```stereo
пирамида 4 4 5 S над A
AC
```

## Частые ошибки

- `сечение M N B` → `сечение MNB`; `M на AA₁` — надёжнее `AA1`.
- Тело не первой строкой (или вовсе забыто) — блок не построится.
- Точка, на которую ссылаются, ещё не определена.
- В условии нарисовано искомое сечение/перпендикуляр/угол — убрать.
- `вершины …` с неверным числом имён (у куба — 8, у пирамиды SABCD — 5).

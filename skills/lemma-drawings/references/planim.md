# Планиметрия — блок ```planim

Редактор «Планиметрия» (`/app/geometry/planim`) и блок ```planim в любом поле.
Чертёж = **журнал операций**: первые шаги — точки или готовая фигура, дальше
построения и пометки. Каждая строка — один шаг. Тела/холста задавать не нужно:
рамка подбирается по точкам сама.

Однострочник для ячейки таблицы: `` `planim: треугольник ABC 5 6 7; H = высота B AC` ``.

Содержание: служебные строки · фигуры · точки · линии · элементы треугольника ·
окружности · пометки · оформление · ссылки на построенные прямые · примеры ·
ошибки.

## Служебные строки

| Строка | Что делает |
|---|---|
| `сетка` | клетчатый фон 1 × 1 — задачи «на клетчатой бумаге» (ОГЭ №18, база №9) |
| `цвет` | цветной чертёж (без строки — чёрно-белый, для печати) |
| `размер 360 300` | рамка рисунка в пикселях (ширина, высота) |
| `H = высота B AC // опускаем высоту` | после `//` — подпись шага (видна при показе по шагам) |
| `# …` | комментарий |

## Фигуры — с них удобно начинать

Буквы — как в учебнике: у треугольника первая слева внизу, вторая наверху,
третья справа; у четырёхугольника — от левого нижнего угла по часовой стрелке
(A — левый нижний, B — левый верхний, C — правый верхний, D — правый нижний).

| Команда | Что строит |
|---|---|
| `треугольник ABC 5 6 7` | по трём сторонам AB, BC, AC; без чисел — произвольный; если точки A, B, C уже стоят — просто контур |
| `прямоугольный треугольник ABC 3 4` | катеты AC и BC, прямой угол C |
| `равнобедренный треугольник ABC 6 5` | основание AC и высота к нему |
| `равносторонний треугольник ABC 6` | сторона |
| `квадрат ABCD 5` | сторона |
| `прямоугольник ABCD 7 4` | AD (низ) и AB (бок) |
| `параллелограмм ABCD 7 4 60` | AD, AB и угол A в градусах |
| `ромб ABCD 5 60` | сторона и угол A |
| `трапеция ABCD 8 4 4` | основания AD (нижнее), BC (верхнее), высота |
| `равнобедренная трапеция ABCD 8 4 3` | то же, боковые стороны равны |
| `прямоугольная трапеция ABCD 8 4 3` | прямой угол A |
| `правильный ABCDEF 3` | правильный многоугольник: сторон — по числу букв, длина стороны |

Своя форма — точками и контуром (`треугольник ABC` по готовым точкам тоже
работает):

```planim
A = (0; 0)
B = (-1; 3)
C = (6; 0)
многоугольник ABC
```

## Точки

| Команда | Что строит |
|---|---|
| `K = (2; 3)` | свободная точка по координатам (y — вверх) |
| `A' = (5; 1)` | имя со штрихом: `A'`, `A''`, `A1'` (на чертеже A′, A″, A₁′); дальше как обычное имя — `AA'`, `X = AA' ∩ BC` |
| `M на AB 1:2` | точка на отрезке, AM : MB = 1 : 2 |
| `K на AB 0,25` | доля от первой точки: 0 — A, 1 — B; больше 1 или меньше 0 — на продолжении |
| `M = середина AC` | середина (без имени — `середина AC`, имя возьмётся следующее свободное) |
| `O = AC ∩ BD` | пересечение прямых (можно `AC x BD`) |
| `H = основание B AC` | основание перпендикуляра из B на AC — только точка, без отрезка |
| `K на окр(O) 30` | точка на окружности под углом 30° (0 — вправо, 90 — вверх) |
| `X = AB ∩ окр(O)` | пересечение прямой с окружностью; `… 2` в конце — именно вторая точка |
| `Q = центр окр(ABC)` | центр окружности как точка |

## Линии

| Команда | Что строит |
|---|---|
| `AC` | отрезок (то же — `отрезок AC`) |
| `прямая AB` | прямая через A и B |
| `луч AB` | луч из A через B |
| `многоугольник ABCD` | контур по точкам |
| `прямая C \|\| AB` | через C параллельно AB |
| `прямая C ⊥ AB` | через C перпендикулярно AB (значок можно набрать `_\|_`) |
| `биссектриса угла ABC` | луч биссектрисы из вершины B |
| `серединный перпендикуляр AB` | середина AB и прямая через неё ⊥ AB |

## Элементы треугольника

| Команда | Что строит |
|---|---|
| `H = высота B AC` | основание H, отрезок BH и значок прямого угла (то же — `перпендикуляр B AC`) |
| `M = медиана B AC` | середина M стороны AC и отрезок BM |
| `L = биссектриса ABC` | точка L на стороне AC и отрезок BL (вершина — средняя буква) |

Высота тупоугольного треугольника на продолжение стороны строится той же
командой — продолжение дорисуется.

## Окружности

| Команда | Что строит |
|---|---|
| `окружность O 3` | центр O, радиус 3 |
| `окружность O A` | центр O, через точку A |
| `Q = описанная ABC` | описанная окружность, Q — центр (имя можно не писать) |
| `I = вписанная ABC` | вписанная окружность |
| `касательные C окр(O)` | обе касательные из точки C: точки касания и отрезки |
| `T = касание C окр(O) 1` | только точка касания (1 или 2) |

## Ссылки на построенные прямые и окружности

В других командах построенную прямую пишут выражением в скобках, а не именем:

| Запись | Что значит |
|---|---|
| `(P\|\|AB)` | прямая через P параллельно AB |
| `(P⊥AB)` | прямая через P перпендикулярно AB |
| `(бис ABC)` | биссектриса угла ABC |
| `окр(O)` | окружность с центром O (уже построенная) |
| `окр(O,A)` / `окр(O;3)` | окружность с центром O через A / радиуса 3 |
| `окр(ABC)` | описанная около ABC |
| `впис(ABC)` | вписанная в ABC |

Пример: `X = AC ∩ (B⊥AC)`, `K = (бис DAB) ∩ BC`.

## Пометки

| Команда | Что рисует |
|---|---|
| `угол ABC` | дуга угла с вершиной B (прямой угол сам рисуется квадратиком) |
| `угол ABC 30` | дуга и подпись 30° |
| `угол ABC 2 α` | две дуги и подпись α (равные углы — одинаковым числом дуг); `?` — искомый |
| `прямой угол ABC` | квадратик, даже если чертёж «на глаз» |
| `равны AB BC` | штрихи равных отрезков; `равны AB BC 2` — по два штриха |
| `длина AB 5` | подпись отрезка: число, буква, `x`, `sqrt(3)`; без текста — настоящая длина |
| `длина AB \frac{a}{2}` | подписи и надписи — формулы LaTeX без долларов: `\frac{a}{2}` или `a/2` — дробь столбиком, `\sqrt{3}`, `a_1`, `\alpha` |
| `текст (3; 4) a` | надпись в точке (например, имя прямой) |
| `заливка ABC` | закрасить многоугольник |

## Оформление

| Команда | Что делает |
|---|---|
| `пунктир AC` | отрезок пунктиром; `сплошная AC` — вернуть; годится и `пунктир окр(O)` |
| `цвет отрезка AB красный` | цвет отрезка: красный, синий, зелёный, оранжевый, фиолетовый; `нет` — снять |
| `цвет AB синий` | без слова «отрезка» — красит сами точки |
| `цвет окр(O) зелёный` | цвет окружности |
| `скрыть O` | точку не рисовать (построения на неё опираются); `показать O` — вернуть |
| `скрыть отрезок AB` | не рисовать кусок линии между двумя точками |
| `скрыть прямую AB` | прямую/луч/отрезок целиком; годятся и `(P\|\|AB)` |
| `скрыть окр(O)` | окружность; так же `скрыть угол ABC`, `скрыть заливку ABC` |
| `показать всё` | вернуть всё скрытое |
| `метка A 135` | куда поставить букву: угол в градусах (0 — справа, 90 — сверху); `метка A авто` |
| `переименовать A K` | новое имя точки |

Цвет виден только со строкой `цвет` в блоке.

## Примеры

Треугольник с высотой и медианой:

```planim
треугольник ABC 6 7 8
H = высота B AC
M = медиана B AC
```

Прямоугольный треугольник, найти гипотенузу:

```planim
прямоугольный треугольник ABC 6 8
длина AC 6
длина BC 8
длина AB ?
```

Равнобедренная трапеция с диагоналями:

```planim
равнобедренная трапеция ABCD 8 4 4
AC
BD
O = AC ∩ BD
равны AB CD
длина AD 8
```

Параллелограмм, биссектриса угла A пересекает BC в точке K:

```planim
параллелограмм ABCD 8 5 60
K = (бис DAB) ∩ BC
AK
угол DAK
угол KAB
```

Вписанный и центральный углы:

```planim
O = (0; 0)
окружность O 3
A на окр(O) 210
B на окр(O) 330
C на окр(O) 80
AC
BC
OA
OB
угол ACB α
угол AOB 2α
```

Касательные из точки к окружности:

```planim
O = (0; 0)
окружность O 2
C = (6; 0)
касательные C окр(O)
OC
```

Вписанная и описанная окружности:

```planim
треугольник ABC 6 7 8
I = вписанная ABC
Q = описанная ABC
```

Фигура на клетчатой бумаге (целые координаты узлов):

```planim
сетка
A = (0; 0)
B = (2; 4)
C = (7; 4)
D = (6; 0)
многоугольник ABCD
```

Высота пунктиром, цветной чертёж, подписи шагов (для теории/решения):

```planim
цвет
треугольник ABC 5 6 7
H = высота B AC // опускаем высоту
пунктир BH
цвет отрезка BH красный
угол BAC 2 α
```

Средняя линия трапеции:

```planim
трапеция ABCD 10 4 4
M = середина AB
N = середина CD
MN
длина AD 10
длина BC 4
длина MN ?
```

## Частые ошибки

- `угол A B C` → `угол ABC`; `сечение`, `треугольник A B C` — имена слитно.
- Ссылка на точку, которой ещё нет: каждая точка определяется строкой выше
  (вершины фигуры определяет сама фигура).
- Построенная прямая по имени (`X = AB ∩ h`) — так нельзя, пиши выражение:
  `X = AB ∩ (C⊥AB)`.
- `цвет отрезка …` без строки `цвет` — останется чёрным.
- Дуги, секторы, сложные кривые — в planim нет; предложи GeoGebra или
  упрощение.

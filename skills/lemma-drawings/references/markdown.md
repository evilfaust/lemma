# Markdown полей Lemma: текст, таблицы, картинки, теория, ТДФ

Все поля с текстом (условие и решение задачи, ответ, теория, пункт ТДФ)
понимают markdown + LaTeX (KaTeX) + блоки чертежей из других справочников.

## Текст и формулы

| Запись | Что даёт |
|---|---|
| `$x^2 - 5x + 6 = 0$` | формула в строке |
| `$$\frac{a+b}{2} \ge \sqrt{ab}$$` | формула отдельной строкой, по центру |
| `**Ответ:**`, `*курсив*` | жирный, курсив |
| `1. пункт` / `- пункт` | нумерованный / маркированный список |
| `$30^\circ$`, `$\angle ABC$` | градусы, угол |
| `$0{,}5$` | десятичная запятая в формуле (без `{,}` KaTeX поставит пробел) |
| `$A_1B_1$`, `$S_{ABC}$` | индексы (составной индекс — в фигурных скобках) |

Всё, что KaTeX не знает, рисуется красным — не используй экзотические пакеты
(`\SI`, `\overarc` и т.п.). Дуга — `\overset{\frown}{AB}`.

## Таблицы

Обычная GFM-таблица: строка `| --- |` отделяет шапку. Вид таблицы задаёт
**строка-директива в фигурных скобках перед таблицей** (несколько — через
запятую: `{без линий, без шапки}`).

| Директива | Вид |
|---|---|
| `{без линий}` | без рамок и заливки — задания на соответствие (ВЕЛИЧИНЫ / ЗНАЧЕНИЯ) |
| `{без шапки}` | строка заголовка скрыта |
| `{бланк}` | бланк ответа: пустые ячейки — место, чтобы вписать от руки |
| `{компактная}` | уменьшенные отступы |
| `{галерея}` | сетка без шапки и рамок: рисунки в ячейках («на каком рисунке…») |
| `{равные колонки}` | столбцы одной ширины, рисунок на всю ячейку |
| `{по центру}` | таблица посередине строки |
| `{линии}` | обычная сетка (отключить автоподбор) |

Без директивы вид подбирается сам: все ячейки тела пустые → бланк; два
столбца вида «А) …» | «1) …» → без линий.

Задание на соответствие с бланком ответа:

```
{без линий}

| ФУНКЦИИ | СВОЙСТВА |
| --- | --- |
| А) $y = x^2$ | 1) возрастает на всей прямой |
| Б) $y = -x$ | 2) убывает на всей прямой |
| В) $y = 2x$ | 3) имеет минимум |

{бланк}

| А | Б | В |
| --- | --- | --- |
|  |  |  |
```

Ряд рисунков — чертежи-однострочники в ячейках:

```
{галерея}

| 1) `plot: x -3 3; y -3 3; f x^2-2` | 2) `plot: x -3 3; y -3 3; f -x^2+1` | 3) `plot: x -3 3; y -3 3; f 2x` |
| --- | --- | --- |
```

## Картинки

`![подпись](адрес)` — адрес даёт Библиотека Lemma (кнопка «Картинка» в поле,
Ctrl+V скриншота, перетаскивание файла). Сам ты адресов не знаешь — если
нужна растровая картинка, оставь пользователю место `![рис1](рис1)` и скажи
вставить файл кнопкой «Картинка». Размер — сразу после картинки:
`![](адрес){S}` — 30 %, `{M}` — 50 %, `{L}` — 70 %, `{XL}` — 100 % ширины
колонки или ячейки.

Растр — последний выход: почти всё школьное рисуется текстом (planim,
stereo, plot, chart, numline) — векторно, без водяных знаков, правится.

## Теория: каллауты и вёрстка

Каллауты — блоки с рамкой и заголовком:

```
:::definition Арифметический корень
Арифметическим квадратным корнем из числа $a \ge 0$ называется…
:::
```

Типы: `definition` (Определение), `theorem` (Теорема), `example` (Пример),
`remark` (Замечание), `proof` (Доказательство), `answer` (Ответ), `qed`,
`note` (Заметка), `condition` (Условие задачи). Текст после типа — заголовок
(можно без него).

Вёрстка (каждая — отдельной строкой):

| Строка | Что делает |
|---|---|
| `:::` | перейти в следующую колонку (многоколоночная статья) |
| `~` / `~~` / `~~~` | вертикальный отступ 1em / 0,5em / 2em |
| `:::geogebra ggb-id:::` | встроенный апплет GeoGebra (id из настроек темы — сам не придумывай) |

Блок ```stereo в теории крутится мышью и листается по шагам; `статично` —
оставить картинкой.

## ТДФ: лист с пропусками (только в пунктах набора ТДФ)

Один текст пункта печатается эталоном (всё видно) и бланком (помеченное
заменено линией той же длины).

| Разметка | Что значит |
|---|---|
| `[[неотрицательное]]` | пропуск в тексте; в формуле — `$b \ge [[0]]$` |
| `\gap{…}` | то же внутри формулы, LaTeX-привычкой |
| ```свойства | нумерованный список формул + общая скобка условий справа (условия — ниже строки `---`) |
| ```соответствие | «левое -> правое» построчно, `# ЛЕВЫЙ -> ПРАВЫЙ` — заголовок; правый столбец перемешивается, под таблицей — таблица ответа |
| ```plot пропуск | в бланке — только оси и сетка, график строит ученик |

```свойства
\sqrt{ab} = \sqrt{a}\cdot\sqrt{b}
\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}
---
a \ge 0,\ b \ge 0
```

```соответствие
# ФУНКЦИИ -> ГРАФИКИ
$y = x^2$ -> `plot: x -3 3; y -1 5; f x^2`
$y = \sqrt{x}$ -> `plot: x -1 5; y -1 3; f sqrt(x)`
```

## Импорт работы целиком

Для перевода целой контрольной (варианты, задачи, ответы) в файл импорта
есть отдельный формат «Импорт работы» (.md с шапкой и вариантами) — если
пользователь хочет именно это, используй скил `lemma-work-import`, а чертежи
внутри задач пиши по этому скилу.

# Чертежи текстом: блоки ```planim и ```stereo

Это команды редакторов Lemma «Планиметрия» и «Стереометрия». Блок пишется
прямо в условии задачи; Lemma строит чертёж сама. Каждый пример ниже проверен
настоящим парсером Lemma (тест `skillWorkImport.test.js` в репозитории).

Содержание: общие правила · планиметрия (фигуры, точки, линии, окружности,
пометки, клетчатая бумага, примеры) · стереометрия (тела, команды, примеры) ·
частые ошибки.

## Общие правила

- Одна команда в строке. Строка с `#` — комментарий.
- Имена точек — латинские заглавные с цифрой-индексом: `A`, `B1`, `K2`
  (на сайте `B1` печатается как B₁). Кириллица-двойник (А, В, С, Н, М, К, О,
  Р, Т, Х) переводится в латиницу сама, но лучше сразу латиницей.
- В командах имена пишутся **слитно**: `AC`, `сечение MNB`, `угол ABC`.
  `сечение M N B` — ошибка, строка пропадёт.
- Переносите только то, что нарисовано на листке. Искомое (сечение, которое
  надо построить; высоту, которую надо провести; угол, который надо найти) не
  рисуйте — чертёж выдал бы ответ. Неизвестную величину можно подписать `?`
  или буквой.
- Без строки `цвет` (печать чёрно-белая). Десятичная дробь — запятая: `0,25`.
- Если фигура задана числами в условии — используйте их (чертёж будет в
  пропорциях). Нет чисел — команда без чисел или правдоподобные значения
  (подписывать длины, которых нет в условии, не надо).

## Планиметрия — ```planim

### Готовые фигуры (с них удобно начинать)

Буквы — как в учебнике: у треугольника первая слева внизу, вторая наверху,
третья справа; у четырёхугольника — от левого нижнего угла по часовой.

| Команда | Что строит |
|---|---|
| `треугольник ABC 5 6 7` | по сторонам AB, BC, AC; без чисел — произвольный |
| `прямоугольный треугольник ABC 3 4` | катеты AC и BC, прямой угол C |
| `равнобедренный треугольник ABC 6 5` | основание AC и высота к нему |
| `равносторонний треугольник ABC 6` | сторона |
| `квадрат ABCD 5` | сторона |
| `прямоугольник ABCD 7 4` | AD (низ) и AB (бок) |
| `параллелограмм ABCD 7 4 60` | AD, AB и угол A в градусах |
| `ромб ABCD 5 60` | сторона и угол A |
| `трапеция ABCD 8 4 4` | основания AD (нижнее), BC (верхнее), высота |
| `равнобедренная трапеция ABCD 8 4 3` | то же, боковые равны |
| `прямоугольная трапеция ABCD 8 4 3` | прямой угол A |
| `правильный ABCDEF 3` | правильный многоугольник: сторон по числу букв |

Своя форма (тупоугольный треугольник, произвольный четырёхугольник) — точками
по координатам и контуром:

```planim
A = (0; 0)
B = (-1; 3)
C = (6; 0)
многоугольник ABC
```

### Точки

| Команда | Что строит |
|---|---|
| `K = (2; 3)` | точка по координатам |
| `M на AB 1:2` | точка на отрезке, AM : MB = 1 : 2 |
| `K на AB 0,25` | доля от A (больше 1 — на продолжении за B) |
| `M = середина AC` | середина |
| `O = AC ∩ BD` | пересечение прямых |
| `H = основание B AC` | основание перпендикуляра из B на AC (только точка) |
| `K на окр(O) 30` | точка на окружности под углом 30° (0 — вправо, 90 — вверх) |
| `X = AB ∩ окр(O)` | пересечение прямой с окружностью |
| `Q = центр окр(ABC)` | центр описанной окружности как точка |

### Линии

| Команда | Что строит |
|---|---|
| `AC` | отрезок |
| `прямая AB` / `луч AB` | прямая / луч из A через B |
| `многоугольник ABCD` | контур по точкам |
| `прямая C \|\| AB` | через C параллельно AB |
| `прямая C ⊥ AB` | через C перпендикулярно AB |
| `биссектриса угла ABC` | луч биссектрисы из B |
| `серединный перпендикуляр AB` | середина и прямая через неё ⊥ AB |
| `X = AC ∩ (B⊥AC)` | построенную прямую в других командах пишут в скобках: `(P\|\|AB)`, `(P⊥AB)`, `(бис ABC)` |

### Элементы треугольника

| Команда | Что строит |
|---|---|
| `H = высота B AC` | основание H, отрезок BH и знак прямого угла |
| `M = медиана B AC` | середина M стороны AC и отрезок BM |
| `L = биссектриса ABC` | точка L на AC и отрезок BL (вершина — средняя буква) |

### Окружности

| Команда | Что строит |
|---|---|
| `окружность O 3` | центр O, радиус 3 |
| `окружность O A` | центр O, через точку A |
| `Q = описанная ABC` | описанная окружность (Q — центр) |
| `I = вписанная ABC` | вписанная окружность |
| `касательные C окр(O)` | обе касательные из точки C с точками касания |
| `T = касание C окр(O) 1` | только первая точка касания |

### Пометки

| Команда | Что рисует |
|---|---|
| `угол ABC` | дуга угла с вершиной B (90° — сам квадратик) |
| `угол ABC 30` | дуга и подпись 30° |
| `угол ABC 2 α` | две дуги и подпись α; `?` — искомый |
| `прямой угол ABC` | значок прямого угла |
| `равны AB BC` | штрихи равных отрезков (`равны AB BC 2` — по два штриха) |
| `длина AB 5` | подпись отрезка: число, буква, `x`, `sqrt(3)` |
| `текст (3; 4) a` | надпись в точке |
| `заливка ABC` | закрасить многоугольник |
| `пунктир AC` | отрезок пунктиром |
| `скрыть O` | точку не рисовать (построения на неё опираются) |

### Клетчатая бумага (ОГЭ №18, база №9)

Строка `сетка` включает клетку 1×1; точки — целыми координатами по клеткам
рисунка. Начало координат — любой удобный узел.

```planim
сетка
A = (0; 0)
B = (2; 4)
C = (7; 4)
D = (6; 0)
многоугольник ABCD
```

### Примеры

Треугольник с высотой и медианой:

```planim
треугольник ABC 6 7 8
H = высота B AC
M = медиана B AC
```

Прямоугольный треугольник, известны катеты, найти гипотенузу:

```planim
прямоугольный треугольник ABC 6 8
длина AC 6
длина BC 8
длина AB ?
```

Трапеция с диагоналями:

```planim
трапеция ABCD 10 4 4
AC
BD
O = AC ∩ BD
длина AD 10
длина BC 4
```

Параллелограмм, биссектриса угла A пересекает BC в точке K:

```planim
параллелограмм ABCD 8 5 60
K = (бис DAB) ∩ BC
AK
угол DAK
угол KAB
```

Вписанный угол опирается на дугу:

```planim
O = (0; 0)
окружность O 3
A на окр(O) 210
B на окр(O) 330
C на окр(O) 100
AC
BC
угол ACB ?
```

Окружность, вписанная в треугольник:

```planim
треугольник ABC 6 7 8
I = вписанная ABC
```

Касательные из точки к окружности:

```planim
O = (0; 0)
окружность O 2
C = (6; 0)
касательные C окр(O)
OC
```

Равнобедренный треугольник с равными боковыми сторонами:

```planim
равнобедренный треугольник ABC 6 4
равны AB BC
угол BAC 50
```

## Стереометрия — ```stereo

### Тело — первая строка блока

| Команда | Тело и вершины |
|---|---|
| `куб 4` | ABCDA1B1C1D1, ребро 4 |
| `параллелепипед 4 3 2` | прямоугольный: AB = 4, AD = 3, AA1 = 2 |
| `призма 3 4 5` | правильная: сторон основания, ребро основания, высота → ABCA1B1C1 |
| `призма 6 2 4` | правильная шестиугольная ABCDEFA1…F1 |
| `пирамида 4 4 5 S` | правильная: сторон основания, ребро основания, высота, вершина → SABCD |
| `пирамида 3 4 5 D` | правильная треугольная DABC |
| `тетраэдр 4 D` | правильный тетраэдр ABCD |

Если вершины на листке названы иначе, второй строкой: `вершины KLMNK1L1M1N1`
(столько имён, сколько вершин, в порядке: основание, затем верх/вершина).
Основание по часовой стрелке (бывает в учебниках): `куб 4 по часовой`.

Ракурс по умолчанию — как в учебнике; менять обычно не нужно
(`вид 30 20` — поворот и наклон).

### Команды

| Команда | Что строит |
|---|---|
| `M на AA1 1:2` | точка на ребре, AM : MA1 = 1 : 2 |
| `K на AB 0,25` | доля от A |
| `M = середина CC1` | середина |
| `MN` | отрезок; невидимые части станут пунктиром сами |
| `прямая MN` | прямая |
| `O = AC ∩ BD` | пересечение прямых |
| `X = MN ∩ (ABC)` | точка пересечения прямой с плоскостью |
| `прямая K \|\| AB` | через K параллельно AB |
| `H = S ⊥ (ABC)` | перпендикуляр из точки на плоскость (основание H и отрезок) |
| `H = M ⊥ AB` | перпендикуляр из точки на прямую |
| `сечение MNB` | сечение тела плоскостью через три точки |
| `плоскость AA1C` | полупрозрачная плоскость через три точки |
| `грань ABCD` | выделить грань |
| `угол A1C (ABC)` | угол между прямой и плоскостью (проекция и дуга) |

### Примеры

Куб, точки на рёбрах (сечение просят построить — его НЕ рисуем):

```stereo
куб 4
M = середина AA1
N на CC1 1:3
```

Правильная четырёхугольная пирамида с высотой SO:

```stereo
пирамида 4 4 5 S
O = AC ∩ BD
AC
BD
SO
```

Правильная треугольная призма, точка на боковом ребре:

```stereo
призма 3 4 5
M = середина BB1
A1M
```

Тетраэдр, середины рёбер:

```stereo
тетраэдр 4 D
K = середина AD
L = середина BC
KL
```

Прямоугольный параллелепипед с диагональю:

```stereo
параллелепипед 4 3 2
AC1
```

Куб со своими буквами:

```stereo
куб 4
вершины KLMNK1L1M1N1
KM1
```

## Частые ошибки

- `сечение M N B` → `сечение MNB` (имена слитно).
- `M на AA₁ 1:2` с индексом-юникодом работает, но надёжнее `AA1`.
- Пирамида с боковым ребром ⊥ основанию, наклонная призма, конус, цилиндр,
  шар — таких тел в редакторе нет: плейсхолдер `![](рисN)`.
- Нарисовано искомое (сечение/высота/угол из вопроса) — уберите.
- Подписаны длины, которых нет в условии, — уберите.

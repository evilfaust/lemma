## Зачем

Новая методика в «Геймификации», родственная пиксель-арту, но с логикой:
числа-подсказки у строк и столбцов — это **ответы примеров устного счёта**,
стоящих прямо в клетках подсказок («√49», «2³», «log₂8»). Ученик сначала
считает, потом по подсказкам выводит рисунок.

Чем отличается от пиксель-арта: там ответ прямо говорит, что красить; здесь
картинку ещё надо вывести. И проверка сильнее — одна неверная подсказка ломает
строку, ученик упирается в противоречие и сам видит, где ошибся.

## Решения по умолчанию

1. **Подсказка = пример прямо в клетке** (способ 1 из обсуждения 29.10.2026).
   Примеры — из генераторов устного счёта с уровнями «Разминка / Как на
   экзамене / Сложнее». Способы 2 (корни уравнения = подсказка строки) и 3
   (часть подсказок закрыта задачами банка) — следующие этапы.
2. **Картинка не решается однозначно → дать готовые клетки** (как в печатных
   нонограммах: 2–5 клеток закрашены заранее), рисунок не искажать.
   Второй путь — «подправить картинку» (переключить пару пикселей) — кнопкой.
3. **Варианты = одна картинка, разные примеры.** У соседей по парте подсказки
   одинаковые по числам, но разные по записи — списать нельзя, ключ один.
4. Размеры **5×5** (знакомство), **10×10** (урок), **15×15** (ДЗ, альбомный лист).
5. Только печать. Онлайн-версии (решать на телефоне) нет: она показала бы
   ученику верность ответов, а проверка сейчас в браузере (BACKLOG, аудит
   25.10.2026).

## Этап 1. Ядро — `ege-tasks/src/utils/nonogram/` (чистое, без React)

- **`clues.js`** — `cluesOf(matrix) → { rows: number[][], cols: number[][] }`,
  `checksum(clues)` (сумма подсказок строк = сумма столбцов = число закрашенных —
  печатается на листе как самопроверка до решения), `maxClue`, `clueCount`.
- **`solver.js`** — решатель «по строкам»: для строки ДП по расстановкам блоков
  (клетка, закрашенная во всех расстановках, — чёрная; пустая во всех — белая),
  проходы строки ↔ столбцы до неподвижной точки. Результат:
  `{ status: 'unique' | 'stuck' | 'contradiction', grid, passes }`.
  Перебора нет НАМЕРЕННО: ученик тоже решает логикой, без угадывания.
  `passes` → трудность «лёгкая / средняя / трудная».
- **`fix.js`** — `suggestGivens(matrix)`: минимум готовых клеток, после которых
  решатель доходит до конца (жадно: открыть клетку, после которой решатель
  продвигается дальше всего). `suggestFlips(matrix)` — для кнопки «подправить
  картинку». Пустые строки/столбцы (подсказка «0») — разрешены, печатаются «0».
- Тест `__tests__/nonogram.test.js`: подсказки известных картинок;
  однозначная / неоднозначная (две диагонали 2×2) / противоречие; готовые
  клетки делают `stuck` → `unique`; контрольная сумма.

## Этап 2. Примеры под нужное число — `utils/nonogram/clueTasks.js`

Задача: на каждое число подсказки (1…15) нужен пример с ровно этим ответом.

- **Пул**: прогнать выбранные категории устного счёта по ~50–100 раз на
  категорию, оставить задания с целым ответом 1…15, разложить по ответу.
  Генераторы дешёвые, пул собирается за миллисекунды.
- **Добор под ответ**: для чисел, которых в пуле не нашлось (обычно 11–15 на
  «Разминке»), — маленькие конструкторы «от ответа»: `a·b − c`, `√(v²)`,
  `log₂ 2^v`, `(v·k):k`, `v² − …` по уровню. 🚨 Ответ считается из того же
  значения, что и печать (как в `utils/oral/kit.js::task`), таблиц руками нет.
- **Ширина**: пример должен влезть в клетку подсказки. Ограничение по
  «печатной длине» TeX (оценка по символам + дробь = высокая клетка), над
  столбцами — строже, чем слева от строк. Слишком широкий — в пул не идёт.
- **Без повторов** внутри варианта (`byExpr` из `questionPlan`), разные записи
  у одного числа подряд.
- Тест `__tests__/nonogramClues.test.js`: каждый пример пересчитывается
  независимо по напечатанному (как `oralAnswers.test.js`) на всех уровнях и
  числах 1…15; варианты одного листа — одни и те же числа, разная запись.

## Этап 4. Печать — лист ученика и ключ

- Лист ученика: шапка (ФИ, класс, вариант), сетка с подсказками-примерами,
  готовые клетки закрашены, строка «Проверь себя: сумма чисел слева = сумме
  сверху = N», краткая инструкция для тех, кто видит нонограмму впервые
  (переключателем, по умолчанию — на 5×5).
- Ключ учителя: рисунок + числа подсказок + ответы примеров по вариантам
  компактной таблицей.
- 5×5 и 10×10 — A4 книжный (5×5 — по два на лист, линия отреза), 15×15 —
  A4 альбомный. Клетка рисунка — квадрат в мм, линии точно под сетку,
  жирная линия каждые 5 клеток.
- Оформление — канон `print-sheet` (монохром, мм, четыре толщины линеек);
  раскладка своя, как у отрезного листа марафона: чистая геометрия в
  `utils/nonogram/layout.js` под тест (ширина зоны подсказок по самому
  длинному ряду, кегль, влезает ли на страницу).

Разрешённые типы перечислены в `ege-tasks/src/utils/egeBaseGeneratedTasks.js`.
Обновление универсального генератора само по себе не разрешает его новые типы
для полного варианта. Подтемы разрешаются по имени только внутри нужной темы
`exam_type = ege_base`; отсутствующая подтема не создаётся автоматически.

Не подключены профильные вопросы про число экстремумов, первообразную и
промежутки монотонности, тригонометрические уравнения с сериями корней,
однородные выражения, двойные углы и sin/cos по тангенсу без подтверждённого
прототипа базы. Простое чтение математического f(x) из соседнего генератора
не заменяет прикладные графики №3 или соответствия №7.

## Поведение

- По умолчанию задачи выбираются из банка. Источник можно менять по каждому
  номеру; конкретный тип генерации выбирается внутри подходящей подтемы.
- Новые задачи создаются на уровне «как на экзамене». Ответ — целое число,
  конечная десятичная дробь либо последовательность цифр.
- В разных вариантах не повторяются сгенерированные условия; учитываются также
  выбранные банковские и зафиксированные условия. Глобальная уникальность по
  всему банку не гарантируется.
- Для новых задач №1, №5 и №6 в одной сборке дополнительно сравниваются данные
  математической модели. Перестановка строк таблицы не делает задачу новой.
- В режиме одинаковых вариантов создаётся один набор задач. Порядок номеров
  полного ЕГЭ сохраняется; перемешивание заданий в этом разделе убрано.
- Фиксация имеет приоритет над генерацией. Нехватка банковских задач останавливает
  сборку до первой записи: номера следующих заданий не сдвигаются.
- При сборке новые задачи сразу сохраняются через `api.createTask`, с темой,
  подтемой и источником. Код присваивает сервер. Условия с графиками — обычные
  редактируемые блоки plot/chart и таблицы; дополнительных файлов не требуется.
- У готовой задачи кнопка-молния открывает предпросмотр. Генерация и отмена
  предпросмотра не пишут в БД; «Сохранить в банк и подставить» создаёт задачу.
  Сохранение и повторное открытие работы используют обычные ID задач.
- Создание доступно редакторам. При сбое записи предыдущий вариант остаётся;
  сообщение указывает, сколько задач уже успело сохраниться в банк.

Проверки: `egeBaseGeneratedTasks.test.js`, `egeBaseTaskGeneratorModal.test.jsx`,
а также существующие независимые проверки ответов арифметики, тригонометрии,
графиков и диаграмм. Тесты используют подставной API и не записывают в боевую БД.

## Настройка страницы

Тренировочные генераторы доступны в «Текстовых задачах»: «Бытовые расчёты · ЕГЭ база №1»,
«Вероятность · ЕГЭ база №5» и «Выбор по таблице · ЕГЭ база №6».
Типы можно тренировать отдельно или объединять на листе, задавая количество
задач каждого типа. Порядок типов одинаков во всех вариантах. Лист можно
распечатать с ответами и сохранить через общий механизм листов генераторов.
При сохранении тренировочного листа задачи остаются в его снимке.
Для костей и монеты на весь тренировочный лист можно собрать до 40
различных условий каждого типа.
«Экспорт .md» по умолчанию открывается в формате «Для импорта в Lemma».
В файл входят варианты, условия, ответы и привязка к теме и подтемам выбранного номера.

- У номера задания постоянно видна метка «Есть генератор», даже при выборе
  из банка. В списке подтем молнией отмечены только поддерживаемые подтемы.
- Источник «Из банка / Новая задача» отделён от выбора конкретного типа.
  У генерации явно показан уровень «Как на экзамене».
- Переключатель «Все задания / С генерацией» фильтрует только отображение,
  не меняет состав полного варианта и номера слотов.
- «Генерация где доступна» учитывает выбранные подтемы и сохраняет фиксацию.
  «Всё из банка» возвращает обычный подбор, сохраняя фильтры и фиксацию.
- Счётчики показывают состав каждого варианта: банк, новые и зафиксированные.
  Главная кнопка сборки находится над списком; параметры печати свёрнуты
  в «Оформление и печать».

## Зачем

Своя альтернатива GeoGebra для **простых** чертежей: треугольник с высотой и
медианой, трапеция с диагоналями, вписанный угол, касательные. Такой чертёж
строится за минуту командами или кликами, живёт текстом рядом с условием
задачи, правится на месте и печатается в одном стиле с остальным листом.
Сложное (геометрические места, анимации, нестандартные построения) —
по-прежнему в GeoGebra: её кнопки в редакторе геометрической задачи остались.

Сделано «по аналогии со стереоредактором» (`STEREO_LIVE_PLAN.md`): тот же
каркас, те же привычки — инструменты с горячими клавишами, строка команд,
журнал шагов, показ по шагам, «Текст», справка «?».

## Решения, принятые при разработке

Пользователь попросил сделать «по аналогии»; развилки ниже закрыты
умолчаниями — их можно пересмотреть.

- **Тела нет.** У стереочертежа есть тело (куб), у плоского чертежа — только
  точки. Чертёж = журнал операций, первые шаги — свободные точки. Готовые
  фигуры («треугольник ABC 5 6 7», «квадрат ABCD 4») — это просто набор шагов
  (точки + контур), вершины потом двигаются мышью.
- **Буквы как в учебнике:** у треугольника A слева внизу, B наверху, C справа;
  у четырёхугольника ABCD — от левого нижнего угла по часовой стрелке (AD —
  нижнее основание трапеции, BC — верхнее).
- **Прямые и окружности — выражениями, а не id шагов:** `(P||AB)`, `(P⊥AB)`,
  `(бис ABC)`, `окр(O,A)`, `окр(O;3)`, `окр(ABC)`, `впис(ABC)`. Шаг ссылается
  только на имена точек, поэтому удаление с зависимыми, переименование и
  выгрузка в текст устроены проще, чем в стерео.
- **Вид** — не ракурс, а сдвиг и масштаб. В блоке ```planim вида нет вовсе:
  чертёж вписывается в рамку `размер` и обрезается по содержимому.
- **Пометки — шаги журнала** (угол, равные отрезки, подпись длины, надпись):
  они появляются в показе по шагам («отметим равные углы»). **Оформление — не
  шаги** (цвет, пунктир, скрытая точка, место буквы).
- **Печать — ч/б по умолчанию** (канон печатного стека), `цвет` — цветной.
- **Клетчатый фон** — строка `сетка` (задачи «на клетчатой бумаге», ОГЭ №18,
  база №8).
- **Точка-вершина печатается без жирной точки** (только буква) — как в
  учебнике; точка внутри отрезка и центр окружности — с точкой.
- **Эфира на телефоны нет.** В стереометрии он нужен, чтобы каждый крутил
  фигуру сам; плоский чертёж учитель рисует на доске мелом. Если понадобится —
  каркас тот же (журнал операций).
- **Библиотека — в той же коллекции `stereo_scenes`**, что у стереочертежей,
  с полем `kind = 'planim'` (а не отдельная коллекция): поля, правила доступа,
  API открытия/правки/удаления и ссылка пособия `/s/<id>` — общие.

## Этап 0 — движок (готов)

Папка `ege-tasks/src/utils/planim/`, чистая логика без React и сети, тесты —
`src/__tests__/planim.test.js` (57).

| Модуль | Содержание |
|---|---|
| `vec2.js` | векторная алгебра на плоскости |
| `refs.js` | выражения прямых и окружностей: разбор, текст, имена точек, ключи |
| `geometry.js` | пересечения прямых и окружностей, описанная/вписанная, касательные |
| `scene.js` | `evaluateScene(scene)` → модель; удаление с зависимыми, переименование, оформление (`applyAction`) |
| `figures.js` | готовые фигуры → шаги журнала (`figureOps`, `FIGURE_KINDS`) |
| `render.js` | модель + вид → примитивы SVG, пометки, буквы, `pick*`, `planimSvgString` |
| `commands.js` | строка команды ⇄ операции, `describeOp`, `opToCommand` |
| `tools.js` | клик инструмента → операции; перетаскивание точек и букв |
| `dsl.js` | блок ```planim ⇄ сцена, SVG для текста, чертёж задачи с исходником |
| `inline.js` | `planim: …` одной строкой (ячейка таблицы) |
| `help.js` | текст справки (сторож проверяет каждый пример) |
| `naming.js` | автоимена: вершины по алфавиту, H — основание, O — центр, M — середина |

**Операции журнала:** `point` (свободная) · `pointOnLine` · `pointOnCircle` ·
`intersect` · `lineCircle` · `circleCircle` · `foot` · `center` · `tangent` ·
`segment` · `line` · `ray` · `parallel` · `perp` · `bisector` · `polygon` ·
`circle` · `fill` · `angle` · `tick` · `measure` · `text`.

Составные команды разворачиваются в несколько шагов: «высота» = основание +
отрезок + прямой угол, «медиана» = середина + отрезок, «биссектриса ABC» =
точка на стороне + отрезок, «касательные» = точки касания + отрезки.

## Этап 1 — редактор (готов)

`/app/geometry/planim`, пункт «Планиметрия» в группе «Геометрия» (секция
`geometry`, новая секция не нужна). Компоненты — `components/planim/`.

- 24 инструмента с горячими клавишами; инструменты, которым нужна точка, сами
  ставят её по клику (на пустом месте — свободную, на линии — точку на линии).
- Перетаскивание: свободная точка (прилипает к сетке, Alt — свободно), точка
  на отрезке (прилипает к ½, ⅓, ¼), точка на окружности (к 15°), буква точки.
- Сдвиг и масштаб листа, «Вписать», сетка редактора.
- Строка команд, журнал шагов (удаление с зависимыми, подписи шагов), показ по
  шагам, отмена по истории (Ctrl+Z откатывает и перетаскивание).
- «Новый чертёж» — 15 готовых фигур с размерами; «Текст» — блок ⇄ чертёж;
  SVG-файл; справка «?».

## Вставка в задачи и теорию (готово)

- Блок ```planim и строка `` `planim: …` `` (в ячейку таблицы) рисуются
  `MathRenderer` (задачи, ученик, печатные листы) и `useMarkdownProcessor`
  (теория).
- Кнопка «Планиметрия» — в тулбаре условия/решения (`FieldInsertToolbar`) и в
  тулбаре теории; курсор внутри готового блока открывает его правку.
- Вкладка «Чертёж» геометрической задачи: «Планиметрия» → `drawing_svg` с
  исходником внутри (`<!--planim:base64-->`), открывается снова на правку.
- Печатные листы считают блок чертежом (размер S/M/L/XL, «сбоку», «без
  чертежей») — он носит те же классы, что стереочертёж.

## Этап 2 — библиотека и пособие ученика (v3.9.267)

- Миграция `1787100000_stereo_scenes_kind.js`: поле `kind` + индекс
  `(owner, kind)`. Аддитивно — старые записи получают пустой `kind` (= стерео).
- «Библиотека» в редакторе (и в окне редактора в задаче/теории), Ctrl+S:
  сохранить как новый, сохранить текущий, открыть, переименовать, удалить,
  открыть ученикам. Окно — общее `stereo/StereoLibrary` с `kind="planim"`.
  В черновике помнится открытый документ, в шапке — «есть несохранённые
  изменения».
- Пособие ученика — та же ссылка `student.oipav.ru/s/<id>`:
  `StudentStereoManual` по `kind` отдаёт `planim/StudentPlanimManual`
  (ленивый чанк). Показ начинается с готовой фигуры (свободные точки и
  контур), дальше листаются построения с подписями шагов; лист вписан по
  всему построению — при листании не прыгает.
- До миграции фронт не ломается: стереобиблиотека грузит все записи,
  планиметрическая говорит «появится после обновления базы».

## Правка построения (v3.9.289)

Готовый объект меняется на месте, а не «удалить и построить заново».
- `editStepCommand(scene, opId, text)` (`commands.js`): команда шага
  разбирается на чертеже ДО этого шага и встаёт на его место; составная
  («H = высота B AC») — несколькими шагами подряд. Первый новый шаг получает
  id старого, подпись к шагу, цвет, пунктир и сдвинутую подпись пометки.
  Имя, которое в новой команде не написано, остаётся прежним; написано
  другое — точка переименовывается во всём дальнейшем журнале (`renamePoint`).
  Отдаёт `broken` — номера дальнейших шагов, которые перестали строиться.
- Где открыть: инструмент «Правка» (Z) — клик по точке, линии, окружности,
  заливке или подписи; двойной клик по линии/окружности/заливке в любом
  инструменте; кнопка `</>` и двойной клик по шагу в журнале; «Изменить
  построение…» в окне точки. Шаг под объектом — `stepOfTarget` (`tools.js`).
- Поле правки — в строке журнала (как в стереоредакторе): Enter — заменить,
  Esc — отмена, ошибка остаётся под полем, чертёж не трогается.

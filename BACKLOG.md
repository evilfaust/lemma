### Методические идеи (без плана)

- **Разноуровневая генерация** одной работы в 3 уровнях под дифференциацию внутри
  класса (`difficulty` 1–5 у задач есть).
- **Персональная траектория:** тепловая карта ученика → индивидуальный лист по его
  слабым темам (сейчас «работа над ошибками» — на класс; профиль слабостей есть в
  летней программе, `weaknessProfile.js`).
- **Классификация типа ошибки** (вычислительная / знак / ОДЗ / понятийная) — «почему»,
  а не только «где».
- **Интервальное повторение формул** поверх ТДФ-карточек.
- **Фронтальный опрос на уроке** (задача на проекторе → ответы с телефонов →
  диаграмма). Близко к эфиру марафона/стерео.
- **Концептуальная вариация (bianshi)** в генераторах: та же функция формулой ↔
  графиком ↔ таблицей ↔ словами, меняется «что дано / что найти». Частично уже
  есть в «Функциях» (задания по графику, диаграммы).
- **Граф пререквизитов тем** («через 2 урока тема, требующая X, а класс завалил X —
  добавить повторение?»).

### BYO-LLM — свой endpoint и токен учителя (только при коммерциализации)

Учитель подключает своего провайдера (url + model + key) для генеративных фич.
Дёшево: все ручки уже OpenAI-совместимы (`/chat/completions`, Bearer), конфиг — env
`TIMEWEB_AI_*`. Эскиз: настройка в `teachers`/`ai_providers`, 🚨 ключ хранить только
на сервере (наружу — маска); ручки берут настройку учителя → фолбэк на env; ключ
кэша `/latex-fix` включает модель; общий хелпер `callLLM()` в pdf-service, чтобы
новые фичи получали BYO бесплатно. Эмбеддинги (bge-m3) сюда НЕ относятся.

### Известные дефекты данных

- **`tasks.code` НЕ уникален** (найдено 06.06.2026): `{N}-{seq}` пересекается между
  ege_base / ege_profile / oge / trig. Нигде не полагаться на уникальность `code` —
  искать по `id` (или `topic`). Если понадобится — префикс типа экзамена
  (`oge-3-028`) или составной уникальный индекс `(topic, code)`.
- **Битые alt у «Решу»** — основная причина `latex_needs_review` (1484 задачи на
  12.10.2026): в alt-тексте формулы маркеры стоят не на месте или вписаны обрывки
  LaTeX (`1 плюс \tfrac65 конец аргумента 16 конец дроби }`). Парсер тут ни при чём:
  вложенные дроби и корни он разбирает верно — каждый «конец …» становится скобкой
  на своём месте (проверено 12.10). Лечится только руками / «🤖 Починить LaTeX».
  TeX-сокращения «Решу» (`\abs`, `\beginmatrix`, `\over`, дуга) — разобраны в v3.9.354.
- **Старые id-less задачи базы** (`source="РЕШУ ЕГЭ — математика базовая"`, без
  `sdamgia_id`) дублируют залитый в июне каталог. Гасить осторожно — они в выданных
  работах.

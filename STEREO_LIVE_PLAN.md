# Живые стереочертежи — план реализации

> Статус (27.09.2026): этапы 0–3 — в проде (v3.9.244–248): редактор, эфир,
> библиотека и пособия, блок ```stereo, цвет точек. Миграции `1786900000` и
> `1787000000` применены. Дальше — опыт уроков.

## Зачем

На доске мелом нельзя сменить ракурс трёхмерной фигуры. Учитель на трудном
моменте урока строит сечение **на ноутбуке**, а у каждого ученика в классе
**на своём телефоне** появляется тот же чертёж — точки, прямые, сечение, —
и его можно крутить самому. Цель — научить *видеть*: какие прямые
пересекаются, какие скрещиваются, где след секущей плоскости.

## Рамки (решения пользователя, 27.09.2026)

- Ученики **только смотрят и крутят**. Никаких инструментов построения у
  ученика нет: строить он учится в тетради, на экзамене телефона не будет.
- Учитель строит **импровизированно**, вместе с классом; заготовки — реже.
- Мел остаётся основным инструментом, приложение — **эпизодически**, на
  трудных моментах. Поэтому запуск эфира должен занимать секунды.
- Учитель — **ноутбук за столом** (мышь/трекпад + клавиатура).
- Проектора в сценарии нет: у каждого ученика **свой** чертёж.
- Тела: **куб, прямоугольный параллелепипед, правильная призма, правильная
  пирамида** (в т. ч. тетраэдр). Тел вращения нет.
- Чертёж «общепринятый» = **параллельная проекция** (без перспективы):
  параллельность и отношения отрезков на прямой сохраняются при любом ракурсе.
- Решения задач банка ученику не показываем (решение 12.07.2026) — эфир и
  пособия к банку задач не привязываются.

## Ключевая идея: журнал операций

Чертёж = тело + **упорядоченный список операций** (`ops`). Каждая операция
ссылается только на уже существующие объекты по имени; движок вычисляет всё
заново из журнала. Отсюда бесплатно:

- **эфир** — учитель дописывает журнал, ученики получают новую версию;
- **отмена** — убрать последнюю операцию;
- **пошаговое пособие** (этап 3) — показать первые *k* операций;
- **строка команд = DSL** для теории/листов (этап 3): текст ⇄ операции.

```js
scene = {
  body: { kind: 'cube', a: 4 },          // + имена вершин по умолчанию
  ops: [
    { id: 'o1', type: 'pointOnLine', name: 'M', a: 'A', b: 'A1', t: 1/3 },
    { id: 'o2', type: 'pointOnLine', name: 'N', a: 'C', b: 'C1', t: 1/2 },
    { id: 'o3', type: 'line',  a: 'M', b: 'N' },
    { id: 'o4', type: 'intersect', name: 'X', l1: ['M','N'], l2: ['A','C'] },
    { id: 'o5', type: 'section', pts: ['M','N','D'] },
  ],
}
```

## Этап 0 — движок (чистая логика, без React и сети)

Папка `ege-tasks/src/utils/stereo/`. Всё покрыто юнит-тестами
(`src/__tests__/stereo*.test.js`).

| Модуль | Содержание |
|---|---|
| `vec3.js` | векторная алгебра, eps относительно размера тела |
| `bodies.js` | построители тел: вершины (3D), рёбра, грани (обход наружу), имена вершин (`A`, `A1` → подпись A₁), центр |
| `scene.js` | `evaluateScene(scene)` → модель: точки (позиция + происхождение + шаг), линии (отрезок/прямая/продолжение), заливки, подсвеченные грани, ошибки по шагам |
| `geometry.js` | пересечение прямых **с проверкой компланарности** (скрещиваются / параллельны / совпадают), прямая ∩ плоскость (след), плоскость по 3 точкам, сечение выпуклого тела плоскостью |
| `camera.js` | ортогональная проекция: `yaw` (вокруг вертикали) + `pitch` (наклон, ограничен), масштаб и центрирование по рамке |
| `visibility.js` | видимость точки и отрезка относительно тела |
| `labels.js` | размещение подписей точек без наложений |
| `render.js` | модель + камера → список примитивов для SVG (линии со сплошными/пунктирными кусками, полигоны, подписи); `stereoSvgString()` — для печати и самопроверки |
| `commands.js` | строка команды ⇄ операция, человеческое описание шага («X = MN ∩ AC») |
| `naming.js` | следующая свободная буква (K, L, M, N, P, Q, R, T, X, Y, Z, E, F, G, H…) |

**Операции (MVP):**

| type | Смысл |
|---|---|
| `pointOnLine` | точка на ребре/отрезке/прямой через две точки, доля `t` от первой (0..1 — на отрезке, вне — на продолжении) |
| `segment` | отрезок между двумя точками |
| `line` | прямая через две точки (рисуется с запасом за крайние точки на ней) |
| `intersect` | точка пересечения двух прямых; если скрещиваются/параллельны — **ошибка шага с понятным текстом**, точка не создаётся |
| `trace` | точка пересечения прямой с плоскостью грани (или плоскостью по 3 точкам) |
| `parallel` | прямая через точку параллельно данной |
| `section` | сечение тела плоскостью по трём точкам → многоугольник (заливка + контур) |
| `face` | подсветить грань / плоскость |
| `style` | цвет/скрыть объект (не меняет геометрию) |
| `rename` | переименовать точку |

**Видимость — точная, а не по пробам.** Тело выпуклое, поэтому точка *P*
скрыта ⇔ луч из *P* к зрителю входит в тело (отсечение луча
полупространствами граней). Для отрезка множество скрытых точек — **один
интервал** (пересечение отрезка с выпуклым «теневым цилиндром» тела), его
концы уточняются бисекцией. Рёбра тела — по нормалям граней (передняя грань
⇒ ребро видно). Точки на передней грани видны, на задней — скрыты.

**Проекция.** Мир: *z* — вверх. Камера: `yaw` (0–360°), `pitch` (−10°…70°,
по умолчанию ≈ 20°). Кнопка «как в учебнике» — стандартный ракурс.

## Этап 1 — учительский редактор (без БД)

Маршрут `/app/geometry/stereo`, пункт меню «Стереометрия» в секции
`geometry` (новая секция не нужна). Роут-компонент — через `React.lazy`.

- **Холст** (`components/stereo/StereoCanvas.jsx`, общий с учеником):
  SVG, вращение мышью (гориз. — yaw, верт. — pitch), колёсико — масштаб,
  двойной клик — сброс ракурса. Подписи — SVG-текст с индексами (A₁).
- **Инструменты** (горячие клавиши): точка на ребре/прямой (клик по линии;
  доля по месту клика, прилипает к ½, ⅓, ⅔, ¼, ¾), отрезок, прямая,
  продолжить ребро, пересечь (клик по двум линиям), след (линия + грань),
  параллельная, сечение (3 точки), подсветить грань.
- **Строка команд** с подсказками: `M на AA1 1:2`, `MN`, `прямая MN`,
  `X = MN ∩ AC` (или `MN x AC`), `след MN ABCD`, `сечение MND`,
  `грань ABCD` … Ошибки — красным под строкой.
- **Журнал шагов** справа: описание каждого шага, удаление последнего
  (отмена, Ctrl+Z), правка доли у точки. Зависимые шаги при удалении
  подсвечиваются и удаляются вместе (с подтверждением).
- **Выбор тела**: куб / параллелепипед / призма (3, 4, 6) / пирамида
  (3, 4, 6), размеры, имя вершины пирамиды (S / D).
- Локальный черновик — в `localStorage` (переживает перезагрузку).

## Этап 2 — эфир на телефоны учеников

**БД — коллекция `stereo_rooms`** (миграция, аддитивно):

| Поле | Тип | Смысл |
|---|---|---|
| `owner` | relation → teachers | учитель |
| `group` | relation → teaching_groups (необяз.) | класс комнаты |
| `code` | text, уникальный индекс | короткий код для ссылки (`10a`) |
| `title` | text | подпись |
| `scene` | json | `{ body, ops }` |
| `camera` | json | `{ yaw, pitch, zoom, seq }` — «смотрите отсюда» |
| `pulse` | json | `{ names, seq }` — «смотрите на MN» |
| `notice` | json | `{ text, seq }` — «MN и AD скрещиваются» |
| `live` | bool | эфир включён |

Правила: запись — только владелец-учитель (superadmin — всё);
`listRule`/`viewRule` = `учитель || live = true` — ученик без логина находит
комнату по коду **только пока идёт эфир**. Персональных данных в комнате нет.
Урок марафона учтён: PocketBase сверяет `viewRule` при доставке realtime →
клиент держит фолбэк-опрос.

**Постоянная комната на класс.** Код по умолчанию из названия класса
(«10А» → `10a`, при занятости — суффикс), редактируется. Учитель один раз
пишет на доске `student.oipav.ru/b/10a`, ученики сохраняют в закладки.

**Учитель:** панель «Эфир» в редакторе — выбор комнаты, «▶ В эфир / ■
Стоп», крупно ссылка; кнопки «Смотрите отсюда» (камера) и инструмент
«Внимание» (клик по объекту → мигает у всех). Каждая операция сразу пишется
в `scene` (обновление записи; журнал маленький).

**Ученик:** `/student/b/{code}` в ученическом приложении (до экрана входа,
как `marathon-live`). Полноэкранный холст, пальцем — вращение, щипок —
масштаб. Переключатель «Следить за учителем» (выключается сам, когда ученик
крутит; кнопка возвращает к ракурсу учителя с анимацией). Новые объекты
вспыхивают при появлении; подпись последнего шага внизу; тосты `notice`.
Вне эфира — «Эфир не идёт», страница сама ждёт начала (опрос).
Надёжность: подписка на запись + опрос раз в 10 с; при возврате вкладки —
перечитать.

Деплой: учительский фронт — малина, ученический — VPS
(`./raspberry/deploy-student-to-vps.sh`), миграция — VPS (бэкап → файл в
`/opt/pocketbase/pb_migrations/` → `systemctl restart pocketbase-ege`).

## Риски

- **UX редактора на скорости урока** — главный. Проверяем после этапа 1 на
  себе, до эфира.
- **Вырожденные случаи** (точка в вершине, прямая в плоскости грани,
  сечение через ребро) — eps относительно размера тела + тесты на каждый.
- **Подписи при вращении** — перебор 8 позиций с оценкой наложений.
- **Интернет в классе** — не код; проверить до первого урока.
